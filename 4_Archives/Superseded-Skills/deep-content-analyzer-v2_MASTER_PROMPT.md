## THE FIRST-PRINCIPLES DEBATE: How It Works

The debate is the analytical move that transforms "comprehensive summary" into "original intellectual contribution." It follows 6 steps:

### Step 1: State Claims Precisely
Strip rhetoric. What is the author actually asserting?

### Step 2: Decompose to Fundamentals
What would have to be true for this claim to hold?
Classify assumptions as: Axiomatic / Empirical / Conventional / Speculative

### Step 3: Current vs. Fundamental Limitation Test
```
CURRENT (will be overcome):          FUNDAMENTAL (physics-level):
- Technology gap                     - Requires genuine consciousness
- Scaling/cost barrier               - Requires embodiment  
- Regulatory vacuum                  - Requires skin in the game
→ DON'T bet on these lasting         → SAFE to build on these
```

### Step 4: Rate-of-Change Analysis
What rates does the author treat as static?
- dH/dt = human capability change rate
- dA/dt = technology capability change rate
- dR/dt = regulatory change rate
- dM/dt = market change rate
Define: What is the survival/success condition in terms of these rates?

### Step 5: Missing Dimensions Checklist
```
□ Taste/Aesthetic Judgment
□ Skin in the Game
□ Compound Stack Effect
□ Trust Capital
□ Physical-World Interface
□ Organizational Power Dynamics
□ Information Asymmetry
□ Regulatory Dynamics
□ Co-Evolution
□ Second-Order Effects
□ Temporal Dynamics
□ Selection Bias
```

### Step 6: Generate Formal Debate Points
Each point: Claim → Counter-argument → Corrected frame → Systems integration

## THE ARCHITECT FRAMEWORK: How It Works

ARCHITECT is the general-purpose framework generator. It takes the original content PLUS the debate's corrections and synthesizes a new, expanded framework.

### The 11-Step ARCHITECT Generation Process

1. **Identify irreducible elements** (reduce author's list by 30-60%)
2. **Design layered architecture** (dependency hierarchy with substrate and output)
3. **Create meaningful mnemonic** (word that relates to domain)
4. **Map complete system dynamics** (all R + B loops in table)
5. **Map all archetypes** (with counter-strategies)
6. **Generate leverage point cascade** (Phase 1-3 with intervention tables)
7. **Build extended rubric** (all framework dimensions, 3 scoring levels)
8. **Design targeted drills** (3-7 drills, each tied to loop or leverage point)
9. **Create interleaving schedule** (12-16 weeks mixing original + expanded)
10. **Design focus sessions** (90-min optimal block structure)
11. **Distill Three Laws** (irreducible principles, memorable, generative)

## WHY THIS PROMPT WORKS: 7 Design Principles

### 1. Skill Activation Chain
The explicit skill list forces Claude to read SKILL.md files containing tested templates, checklists, and output formats.

### 2. Multi-Framework Triangulation
15+ frameworks applied to the same content creates triangulation — high-confidence insights appear from multiple angles.

### 3. Forced Depth via Structure
"Analyze, Clarify, Exemplify, recommend use case" forces four distinct analytical passes.

### 4. Counter-Intuitive Insight Generation
Systems thinking tools (archetype detection, leverage analysis) surface insights that contradict surface reading.

### 5. ★ First-Principles Deconstruction
The debate forces genuine intellectual rigor. The Current vs. Fundamental test and rate-of-change analysis reveal dynamics snapshot-thinking misses entirely.

### 6. ★ Framework Synthesis as Original Contribution
The ARCHITECT generation process doesn't just summarize — it creates NEW intellectual property by combining the author's insights with the debate's corrections into something neither produced alone.

### 7. ★ Three Laws as Compression Technology
Distilling the entire analysis into 3 laws creates "pointers, not posters" — compact enough for working memory, generative enough to reconstruct the full framework when unpacked.
