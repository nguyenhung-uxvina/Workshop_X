## System Definition

> **"Hệ thống Mô phỏng Vũ khí Hải quân (NWTS) huấn luyện kíp chiến đấu tàu chiến vận hành pháo hạm AK-176 (76mm) và hệ thống phòng thủ tầm gần AK-630 (30mm CIWS). Đây là các vũ khí chính trên tàu hộ vệ, tàu tên lửa của Hải quân Việt Nam, có nhiệm vụ tiêu diệt mục tiêu mặt nước, phòng không tầm thấp, và đánh chặn tên lửa chống hạm."**

**English Definition:**
> The Naval Weapons Training Simulator (NWTS) trains ship combat crews to operate the AK-176 (76mm) naval gun and AK-630 (30mm CIWS - Close-In Weapon System). These are primary weapons on Vietnamese Navy frigates and missile boats, tasked with engaging surface targets, low-altitude air defense, and anti-ship missile interception.

### 1.5 Three Flow Types Analysis (Pahl & Beitz Framework)

| Flow Type | Real Naval Weapon | Simulator Manifestation | Critical Parameters |
|-----------|------------------|------------------------|---------------------|
| **Material** | Ammunition, propellant | Simulated counter | Round count, type |
| **Energy** | Recoil, rotation | Audio/visual feedback | Firing rate, vibration |
| **Signal** | Radar data, fire control | Network, displays | Track, lead, solution |

**Primary Flow:** Signal (Radar → Fire Control → Gun Mount → Fire → Hit Assessment)

**Unique Characteristic:** PLATFORM MOTION - Tàu lắc liên tục, pháo phải ổn định và bù trừ!

## 3. Skill 1: Feynman Technique Analysis

### 3.1 Concept: "Naval Fire Control System"

#### 60-Second Explanation (ELI12)

Hãy tưởng tượng bạn đứng trên ván lướt sóng đang lắc và cố ném bóng trúng mục tiêu đang chạy.

**Fire Control System giống như:**
- Bạn đứng trên ván lắc (tàu lắc)
- Mục tiêu đang chạy (tàu địch di chuyển)
- Phải ném trước chỗ mục tiêu sẽ đến (lead angle)
- Phải bù cho ván đang lắc (stabilization)
- Máy tính tính toán hết cho bạn!

**FCS làm 3 việc chính:**
1. **Dự đoán**: Mục tiêu sẽ ở đâu khi đạn bay tới
2. **Bù trừ**: Tàu đang lắc thế nào, pháo phải xoay ngược
3. **Chỉ thị**: Bảo pháo hướng nào, góc nào để bắn trúng

#### Everyday Analogy

🏠 **Ví dụ hàng ngày:**

Giống như **camera chống rung + theo dõi tự động** trên điện thoại:
- **Tàu lắc** = Tay bạn run
- **Chống rung OIS** = Stabilization
- **Theo dõi khuôn mặt** = Target tracking
- **Chụp liên tục, chọn ảnh đẹp nhất** = Optimal fire time
- **AI tự động lấy nét** = Fire control computer

### 3.2 Concept: "CIWS - Close-In Weapon System"

#### Deep Analysis (5-Layer Understanding)

**Layer 1 - Surface:** CIWS là hệ thống phòng thủ cuối cùng, bắn tự động tiêu diệt tên lửa chống hạm.

**Layer 2 - Mechanism:**
```
INCOMING MISSILE → RADAR DETECTS → FCS TRACKS → CIWS FIRES → DESTROY
       ↓                ↓              ↓             ↓           ↓
    3km away         3 sec         2 sec       5000 rpm      Wall of lead
```

**Layer 3 - Context:**

| Threat | Distance | Time Available | CIWS Response |
|--------|----------|----------------|---------------|
| Anti-ship missile | 3 km | 10-15 sec | Detect, track, engage |
| Mach 0.9 missile | 1.5 km | 5-7 sec | Rapid engagement |
| Mach 2 missile | 1 km | 2-3 sec | Autonomous, no time |
| Sea-skimmer | 500m | 1-2 sec | Last resort |

**Layer 4 - System:**

```
┌─────────────────────────────────────────────────────────────────────┐
│                    CIWS ENGAGEMENT SEQUENCE                          │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  T-15 sec: SEARCH RADAR detects incoming                            │
│       │    "Vampire, vampire! Missile inbound, bearing 270"          │
│       ▼                                                              │
│  T-12 sec: TRACKING RADAR locks on                                  │
│       │    Target designated to CIWS                                │
│       ▼                                                              │
│  T-10 sec: CIWS AUTONOMOUS engages                                  │
│       │    "CIWS tracking, engaging"                                │
│       ▼                                                              │
│  T-8 sec: FIRST BURST fired                                         │
│       │    500 rounds in 6 seconds                                  │
│       ▼                                                              │
│  T-5 sec: ASSESS and re-engage if needed                           │
│       │    Radar confirms hit or miss                               │
│       ▼                                                              │
│  T-3 sec: SECOND BURST if target survives                          │
│       │    Last chance                                              │
│       ▼                                                              │

│                                                                      │
```

### 3.3 Concept: "Lead Angle"

#### Technical Deep Dive

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    LEAD ANGLE (Góc Phủ trước)                            │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  THE PROBLEM:                                                            │
│  ┌─────────────────────────────────────────────────────────────────┐    │
│  │                                                                  │    │
│  │      Target NOW ───────────────────► Target THEN                │    │
│  │           ●                              ●                      │    │
│  │                                                                  │    │
│  │      If you aim HERE,                 Target will be HERE       │    │
│  │      projectile misses!               when projectile arrives!  │    │
│  │                                                                  │    │
│  │                                                                  │    │
│  │      Time of Flight: 3-5 seconds for AK-176                    │    │
│  │      Target moves: 30m/s × 4s = 120m!                          │    │
│  │                                                                  │    │
│  └─────────────────────────────────────────────────────────────────┘    │
│                                                                          │
│  THE SOLUTION: LEAD ANGLE                                                │
│  ┌─────────────────────────────────────────────────────────────────┐    │
│  │                                                                  │    │
│  │                           Target THEN                           │    │
│  │                               ●                                 │    │
│  │                              ╱│                                 │    │
│  │                            ╱  │ Lead                            │    │
│  │                          ╱    │ distance                        │    │
│  │                        ╱      │                                 │    │
│  │      Target NOW      ╱       │                                  │    │
│  │           ●─────────────────────                                │    │
│  │             ↘                                                    │    │
│  │               Lead angle                                        │    │
│  │                 ↘                                               │    │
│  │                   ╲                                             │    │
│  │                     ╲                                           │    │
│  │                       ● Ship (firing)                           │    │
│  │                                                                  │    │
│  └─────────────────────────────────────────────────────────────────┘    │
│                                                                          │
│  FORMULA (simplified):                                                   │
│  Lead Angle = arctan(Target Speed × TOF / Range)                        │
│                                                                          │
│  EXAMPLE:                                                                │
│  ├── Target: 30 knots (15.4 m/s), crossing                             │
│  ├── Range: 5 km                                                        │
│  ├── TOF: 5 seconds (76mm at 5km)                                      │
│  ├── Lead distance: 15.4 × 5 = 77m                                     │
│  └── Lead angle: arctan(77/5000) = 0.88° ≈ 15 mils                    │
│                                                                          │
│  FCS CALCULATES THIS AUTOMATICALLY!                                      │
│                                                                          │
└─────────────────────────────────────────────────────────────────────────┘
```

### 3.4 Common Misconceptions

| Misconception | Reality | Impact on Design |
|---------------|---------|-----------------|
| "Point and shoot" | Requires complex FCS | Must simulate FCS |
| "Ship is stable" | Ship constantly moves | Simulate motion |
| "Direct aim works" | Need lead, elevation | Calculate lead |
| "Gunner controls all" | FCS does calculation | FCS interface |
| "CIWS is slow" | Autonomous, 6-8 sec | Fast reaction |
| "Manual is better" | Auto often faster | Mode selection |

**Application:**
❓ Khi tàu lắc 15° và đang bắn mục tiêu, pháo phải làm gì để duy trì ngắm chính xác?

**Edge Case:**
❓ Trong chế độ CIWS tự động, khi nào kíp chiến đấu cần can thiệp thủ công?

#### Drill 1.1: Surface Target Lead
**Time:** 20 minutes  
**Task:** Calculate lead angle:

| Target Speed | Crossing Angle | Range | TOF | Your Lead |
|--------------|----------------|-------|-----|-----------|
| 20 knots | 90° | 5 km | 5s | |
| 30 knots | 45° | 8 km | 8s | |
| 15 knots | 30° | 3 km | 3s | |

**Model Answer:**
| Speed | Angle | Range | TOF | Lead Distance | Lead Angle |
|-------|-------|-------|-----|---------------|------------|
| 20 kts (10.3 m/s) | 90° | 5 km | 5s | 51.5m | 0.59° |

| 15 kts (7.7 m/s) | 30° | 3 km | 3s | 11.6m | 0.22° |
