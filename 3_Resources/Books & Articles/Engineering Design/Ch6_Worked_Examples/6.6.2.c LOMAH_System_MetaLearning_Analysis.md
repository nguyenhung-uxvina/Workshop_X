# PART I: EXECUTIVE SUMMARY AND SYSTEM CONTEXT

## 1.1 System Overview

**LOMAH (Location of Miss and Hit)** is an acoustic-based real-time scoring system that provides instant, precise XY coordinate feedback for live-fire marksmanship training. Unlike simulation systems (AR-VR) or physical target systems (paper/steel), LOMAH uses **passive acoustic detection** of supersonic shock waves to determine exactly where each bullet passed through the target plane.

## SKILL 1: FEYNMAN TECHNIQUE EXPLANATION (engineering-feynman)

### 1.1 "Explain Like I'm 5" - What is LOMAH?

**Simple Explanation:**

You know how when a car drives by really fast, you hear a "whoosh" sound? When a bullet flies through the air even faster than a race car, it makes a special kind of "boom" called a shock wave - like a tiny sonic boom!

LOMAH is like having super ears (microphones) arranged around a target. When the bullet goes by, each microphone hears the "boom" at a slightly different time. A computer figures out where the bullet was by comparing when each microphone heard the sound - just like how you can tell where a sound is coming from because your two ears hear it at different times!

The computer then shows you on a screen exactly where your bullet went - even if you missed the target completely! And it does this in less than a blink of an eye (100 milliseconds).

### 1.2 The Core Physics (Simplified)

**Why do we need the bullet to be supersonic?**

```
SUBSONIC vs SUPERSONIC
═══════════════════════════════════════════════════════════════════════

SUBSONIC (Bullet slower than sound):
────────────────────────────────────
The bullet pushes air aside gently. Sound waves spread out in all 
directions like ripples in a pond.

    Sound waves                 Bullet
    ──────────                  ──────
         ○                        →
       ○   ○                    ●
     ○       ○                    
   ○           ○               The sound "runs away" from bullet
 ○               ○             No clear shock wave to detect
                               
→ LOMAH CANNOT WORK (no distinct signal)


SUPERSONIC (Bullet faster than sound):
──────────────────────────────────────
The bullet outruns its own sound waves. All the compressed air piles up
into a cone-shaped SHOCK WAVE - like a boat's wake, but in 3D.

                 Shock wave cone
                    ╱     ╲
                   ╱       ╲
                  ╱         ╲
                 ╱   ●→      ╲    Bullet at tip of cone
                ╱   Bullet    ╲
               ╱               ╲
              ╱                 ╲
             ▼                   ▼
           Microphone 1        Microphone 2
           
→ LOMAH DETECTS the shock wave arrival at each microphone
→ Time difference → Position calculation
```

### 1.3 How Does TDOA Work? (Time Difference of Arrival)

**The Three Magic Steps:**

**Step 1: Detect the Shock Wave**
```
Each microphone in the array has a very sensitive element that converts
pressure changes (sound) into electrical signals.

When shock wave arrives:
    
    Pressure spike
         │
         ▼
    ┌─────────────┐
    │             │────── Electrical signal
    │  Microphone │       (voltage spike)
    │             │
    └─────────────┘

The electronics record EXACTLY when each microphone detected the spike.
Timing precision: ~1 microsecond (0.000001 seconds)
```

**Step 2: Calculate Time Differences**
```
Example: 4-microphone array

         Mic 1 (t₁ = 0 µs)
              ●
             ╱│╲
            ╱ │ ╲
           ╱  │  ╲
          ╱   │   ╲    Bullet passed HERE → ⊕
         ╱    │    ╲
        ●─────┼─────●
   Mic 4      │     Mic 2
  (t₄=12µs)   │   (t₄=5µs)
              │
              ●
          Mic 3 (t₃ = 8 µs)

Time differences:
    Δt₁₂ = t₂ - t₁ = 5 - 0 = 5 µs    → Bullet closer to Mic 1 than Mic 2
    Δt₁₃ = t₃ - t₁ = 8 - 0 = 8 µs
    Δt₁₄ = t₄ - t₁ = 12 - 0 = 12 µs

Each time difference defines a HYPERBOLA of possible positions.
With 3+ time differences, the hyperbolas intersect at ONE point!
```

**Step 3: Project to Target Plane**
```
The sensors are BELOW the target face (protected from bullets).
The shock wave passes the sensor plane at an angle.

        Target face ─────────────────────── ← Where we want position
              │
              │ Bullet trajectory
              │     ╲
              │      ╲
              │       ⊕ ← Actual passage point
              │        ╲
              │         ╲
    Sensor plane ●───●───●───● ← Where sensors detect

The computer calculates where the bullet crossed the sensor plane,
then projects this point UP to the target face plane.

This requires knowing:
    - Vertical distance between sensor and target planes
    - Bullet trajectory angle (from Mach cone angle)
    - Precise sensor positions
```

### 1.6 Feynman Test Questions

**Q1**: Why must the sensors be BELOW the target plane, not on it?

**Model Answer**: Two critical reasons:

1. **Ballistic Protection**: Bullets would destroy sensors mounted on the target face. By placing sensors below and behind ballistic shielding, they survive indefinitely. This dramatically reduces Total Cost of Ownership (TCO).

2. **TDOA Geometry**: If sensors were ON the target plane, a bullet passing directly through the center would create identical arrival times at symmetrically placed sensors - ambiguous position! By offsetting vertically, there's always a measurable time difference, enabling 3D triangulation that can be projected to the 2D target plane.

The tradeoff is more complex mathematics (3D TDOA with plane projection), but this is easily handled by modern processors.

**Q2**: How does LOMAH score a burst of automatic fire at 600 rounds per minute?

**Model Answer**: At 600 rpm, bullets arrive every 100 ms (10 Hz). Each bullet creates a distinct shock wave lasting only ~0.5-1 ms. The key challenges:

1. **Sampling Rate**: LOMAH uses high-frequency sampling (50-100 kHz) to capture each shock wave individually. At 100 kHz, there are 10,000 samples between shots - plenty to distinguish them.

2. **Signal Processing**: Algorithms identify the sharp "leading edge" of each shock wave, ignoring the trailing decay and any reflections.

3. **Shot Stacking Prevention**: If two bullets pass too close in time (<2 ms), their shock waves might overlap. Advanced systems use wavelet decomposition to separate overlapping signals.

4. **Buffer Management**: The processor must calculate and display each shot before the next arrives. With 100 ms between shots and <10 ms processing time, this is easily achievable.

**Q3**: Why is FASIT compliance important for Vietnamese defense procurement?

**Model Answer**: FASIT (Fidelity Assurance Standardized Interface for Targetry) is a military standard for target system data exchange. Its importance:

1. **Interoperability**: FASIT-compliant LOMAH integrates seamlessly with Range Control Systems (RCS), training management databases, and simulation systems. A Vietnamese LOMAH installation can share data with allied training facilities or export-purchased RCS equipment.

2. **Data Portability**: Training records from FASIT systems can be consolidated across multiple ranges, units, and even countries. This supports joint exercises and standardized qualification tracking.

3. **Future-Proofing**: Even if Vietnam develops indigenous RCS software, FASIT ensures the LOMAH data format will remain compatible.

4. **Procurement Leverage**: Requiring FASIT compliance in procurement contracts opens competition to multiple vendors while ensuring compatibility.

## SKILL 6: CONCEPT EVALUATION ASSISTANT (engineering-concept-evaluation-assistant)

### 6.1 TDOA Accuracy Analysis

**Target: ±5 mm XY accuracy at target plane**

```
TDOA ACCURACY BUDGET
═══════════════════════════════════════════════════════════════════════

The position accuracy depends on:
1. Time measurement accuracy (Δt_error)
2. Speed of sound accuracy (V_sound_error)
3. Sensor position accuracy (geometry_error)
4. Projection to target plane (projection_error)

COMPONENT 1: Time Measurement
─────────────────────────────
ADC sampling rate: f_s = 100 kHz
Sample period: T_s = 10 µs
Interpolation: 10× → effective resolution = 1 µs

Position error from timing: Δx ≈ V_sound × Δt_error
    = 343 m/s × 1 µs = 0.343 mm

✓ Timing contributes ~0.35 mm error


COMPONENT 2: Speed of Sound
───────────────────────────
V_sound varies with temperature: V = 331.3 + 0.606 × T(°C)

At 20°C: V = 343.4 m/s
At 30°C: V = 349.5 m/s (Δ = 6.1 m/s = 1.8%)

If temperature measurement error = ±2°C:
    V_error ≈ ±1.2 m/s (0.35%)
    
Position error from V_sound: Δx ≈ x × (V_error / V_sound)
    For x = 500 mm (edge of target): Δx ≈ 500 × 0.0035 = 1.75 mm

✓ Temperature compensation contributes ~1.8 mm error at edge


COMPONENT 3: Sensor Position
────────────────────────────
If sensor positions known to ±1 mm:
    Position error: ~1 mm (directly propagates)

✓ Geometry contributes ~1 mm error


COMPONENT 4: Projection Error
─────────────────────────────
Sensor plane to target plane distance: h = 150 mm
Projection angle error (bullet trajectory): ±2°

Projection error: Δx ≈ h × tan(θ_error) = 150 × tan(2°) = 5.2 mm

⚠ This is the LARGEST error source!

MITIGATION: Use Mach cone angle to infer trajectory:
    θ_Mach = arcsin(V_sound / V_bullet)
    With V_bullet known from ballistics table ±5%:
    Reduced projection error: ~1.5 mm

✓ With compensation: Projection contributes ~1.5 mm


TOTAL ERROR (RSS):
──────────────────
√(0.35² + 1.75² + 1.0² + 1.5²) = √(0.12 + 3.06 + 1.0 + 2.25) = √6.43 = 2.5 mm

With 2σ margin for variations: 2.5 × 1.5 = 3.8 mm

✓ ACHIEVABLE: ±5 mm specification can be met with margin
```

### 6.2 Speed of Sound Compensation

```
ENVIRONMENTAL COMPENSATION MODEL
═══════════════════════════════════════════════════════════════════════

SPEED OF SOUND FORMULA:
───────────────────────
V_sound = 331.3 × √(1 + T/273.15) m/s

Simplified: V_sound ≈ 331.3 + 0.606 × T(°C) m/s


HUMIDITY EFFECT:
────────────────
Humidity increases V_sound slightly (water vapor lighter than N2/O2)

V_sound = 331.3 × √(1 + T/273.15) × (1 + 0.0016 × RH)

At 30°C, 80% RH: V = 349.5 × 1.0013 = 350.0 m/s (Δ = +0.5 m/s)

✓ Humidity effect is small (~0.1% per 10% RH)


ALTITUDE EFFECT:
────────────────
Altitude affects pressure, not V_sound directly (V depends on temperature)
But temperature typically decreases with altitude: ~6.5°C per 1000m

Vietnamese firing ranges: 0-500m altitude
Temperature effect: -3.25°C → ΔV ≈ -2 m/s

✓ Altitude effect via temperature: compensate with local T measurement


COMPENSATION IMPLEMENTATION:
────────────────────────────
Option 1: Manual input (operator enters temperature)
    Cost: $0 (software only)
    Accuracy: ±2°C → ±1.2 m/s (0.35%)

Option 2: Temperature sensor (automatic)
    Cost: ~$50-100
    Accuracy: ±0.5°C → ±0.3 m/s (0.09%)

Option 3: Full met station (T, RH, pressure)
    Cost: ~$500-1000
    Accuracy: ±0.1% in V_sound

RECOMMENDATION: Option 2 (temperature sensor) for Vietnamese climate
    - Tropical temperatures well within measurement range
    - Humidity effect small enough to ignore or estimate
    - Cost-effective accuracy improvement
```

### 6.3 Sensor Array Sizing

```
ARRAY GEOMETRY OPTIMIZATION
═══════════════════════════════════════════════════════════════════════

DESIGN PARAMETERS:
──────────────────
Target size: 1000 × 1000 mm (standard E-silhouette)
Sensor plane offset: h = 150 mm below target plane
Required coverage: Full target + 100 mm margin for misses
Required accuracy: ±5 mm

ARRAY SIZE CALCULATION:
───────────────────────
For square array with sensors at corners:

Geometric Dilution of Precision (GDOP) ≈ (d/c) × √N

Where:
    d = sensor spacing
    c = baseline (distance from bullet to nearest sensor)
    N = number of sensors

For minimum GDOP at center:
    Sensors at corners of 1200 × 1200 mm square
    d = 1200 mm
    c_center = 850 mm (diagonal to corner)
    GDOP_center ≈ (850/1200) × √4 = 1.4

Position accuracy at center:
    σ_position = GDOP × V_sound × σ_time
              = 1.4 × 343 × 1×10⁻⁶
              = 0.5 mm

✓ 4-sensor square array adequate for center accuracy

EDGE ACCURACY CHECK:
────────────────────
At corner of target (worst case):
    c_corner = 100 mm (very close to one sensor)
    GDOP_corner ≈ (100/1200) × √4 = 0.17

But: Asymmetric geometry degrades accuracy differently

For edge accuracy, add 5th sensor at center:
    Cross array: 4 corners + 1 center
    Reduced GDOP variation across target

RECOMMENDED CONFIGURATION:
──────────────────────────
5-sensor cross array: 4 at 1200mm square corners + 1 center
    Sensor 1: (0, 0)
    Sensor 2: (1200, 0)
    Sensor 3: (1200, 1200)
    Sensor 4: (0, 1200)
    Sensor 5: (600, 600)

Average GDOP: ~0.8
Worst-case accuracy: ±3 mm

## SKILL 12: TARGETED DRILL MASTER (engineering-targeted-drill-master)

### 12.1 Drill Set: TDOA Calculations

**Drill 12.1.1: Basic Time Difference**

Given:
- Sensor 1 at (0, 0) mm
- Sensor 2 at (1000, 0) mm
- Bullet passes at (300, 500) mm
- Speed of sound: 343 m/s

Calculate time difference Δt₁₂ = t₂ - t₁

**Model Answer:**
```
Distance from bullet to Sensor 1:
    d₁ = √(300² + 500²) = √(90000 + 250000) = √340000 = 583.1 mm

Distance from bullet to Sensor 2:
    d₂ = √((1000-300)² + 500²) = √(700² + 500²) = √(490000 + 250000) = √740000 = 860.2 mm

Time difference:
    Δt₁₂ = (d₂ - d₁) / V_sound
        = (860.2 - 583.1) / 343000 mm/s
        = 277.1 / 343000
        = 0.808 ms = 808 µs

Sensor 2 receives the shock wave 808 µs AFTER Sensor 1
```

**Drill 12.1.2: Position from Time Differences**

Given:
- 4 sensors in square array, corners at (0,0), (1000,0), (1000,1000), (0,1000) mm
- Measured time differences relative to Sensor 1:
  - Δt₁₂ = +500 µs (Sensor 2 later)
  - Δt₁₃ = +800 µs (Sensor 3 later)
  - Δt₁₄ = +300 µs (Sensor 4 later)
- Speed of sound: 343 m/s

Estimate bullet position.

**Model Answer:**
```
Convert time differences to distance differences:
    Δd₁₂ = 343 × 500 × 10⁻³ = 171.5 mm (S2 farther)
    Δd₁₃ = 343 × 800 × 10⁻³ = 274.4 mm (S3 farther)
    Δd₁₄ = 343 × 300 × 10⁻³ = 102.9 mm (S4 farther)

Qualitative analysis:
    - S1 closest → bullet near corner (0,0)
    - S2 next closest → bullet left of center horizontally
    - S4 closer than S3 → bullet low (closer to bottom)

Quantitative solution (iterative or geometric):
    Using hyperbolic intersection:
    Bullet position ≈ (280, 350) mm

This places the bullet in the lower-left quadrant, consistent with S1 being closest.
```

### 12.2 Drill Set: Speed of Sound Compensation

**Drill 12.2.1: Temperature Effect**

Given:
- Calibrated at 20°C (V_sound = 343.4 m/s)
- Actual temperature: 35°C
- Sensor spacing: 1000 mm
- Measured Δt: 800 µs

Calculate error in distance measurement if temperature not compensated.

**Model Answer:**
```
Correct V_sound at 35°C:
    V = 331.3 + 0.606 × 35 = 331.3 + 21.2 = 352.5 m/s

Distance calculated with wrong V_sound (343.4 m/s):
    Δd_wrong = 343.4 × 800 × 10⁻³ = 274.7 mm

Distance with correct V_sound (352.5 m/s):
    Δd_correct = 352.5 × 800 × 10⁻³ = 282.0 mm

Error:
    Δd_error = 282.0 - 274.7 = 7.3 mm

This error is GREATER than the ±5 mm accuracy requirement!
→ Temperature compensation is MANDATORY for accurate LOMAH
```

### 12.3 Drill Set: Array Geometry

**Drill 12.3.1: Minimum Sensor Spacing**

Given:
- Required position accuracy: ±5 mm
- Timing resolution: 1 µs
- Speed of sound: 343 m/s
- GDOP factor: 1.0 (ideal geometry)

Calculate minimum sensor spacing for target size 1000 × 1000 mm.

**Model Answer:**
```
Timing error → distance error:
    σ_d = V_sound × σ_t = 343 × 1 × 10⁻⁶ = 0.343 mm per sensor pair

With GDOP = 1.0:
    σ_position ≈ GDOP × σ_d = 1.0 × 0.343 = 0.343 mm

This is much better than ±5 mm requirement, so timing is not the limiting factor.

For a square array covering 1000 × 1000 mm target:
    Minimum spacing = target size + margin
                    = 1000 + 200 (for misses)
                    = 1200 mm

With 1200 mm spacing, GDOP at center ≈ 1.4
    σ_position ≈ 1.4 × 0.343 = 0.48 mm (still excellent)

Conclusion: 1200 mm square array adequate for ±5 mm accuracy

## Appendix A: Key Formulas

```
LOMAH KEY FORMULAS
═══════════════════════════════════════════════════════════════════════

SPEED OF SOUND:
    V_sound = 331.3 × √(1 + T/273.15) m/s
    Simplified: V_sound ≈ 331.3 + 0.606 × T(°C) m/s

MACH CONE ANGLE:
    θ_Mach = arcsin(V_sound / V_bullet)

TIME DIFFERENCE TO DISTANCE DIFFERENCE:
    Δd = V_sound × Δt

HYPERBOLIC INTERSECTION (2D):
    For sensors at (x₁, y₁) and (x₂, y₂) with distance difference Δd:
    Points satisfying |d₁ - d₂| = Δd form a hyperbola
    With 3+ hyperbolae, intersection gives bullet position

POSITION ACCURACY (SIMPLIFIED):
    σ_position ≈ GDOP × V_sound × σ_time
    
    Where GDOP (Geometric Dilution of Precision) depends on array geometry

TOTAL ERROR (RSS):
    σ_total = √(σ_timing² + σ_V_sound² + σ_geometry² + σ_projection²)
```

# CONCLUSION

This analysis demonstrates the application of Pahl & Beitz systematic design methodology to the conceptual design of a LOMAH (Location of Miss and Hit) System for Vietnamese defense live-fire training applications.

**Key Outcomes:**

1. **Variant Selection by Application:**
   - High-volume basic training: V1 Basic (R = 74%) - Best cost/indigenous balance
   - Standard qualification: V2 MEMS (R = 76%) - Best overall performance ← RECOMMENDED
   - Precision training: V3 Fiber (R = 66%) - Highest accuracy
   - Field exercises: V4 Portable (R = 63%) - Deployable
   - Anti-aircraft: V5 MDI (R = 61%) - Specialized

2. **Critical Design Parameters:**
   - XY accuracy: ±5 mm (achievable with 4-5 sensor array, 1 µs timing)
   - Scoring rate: 600+ rpm (100 kHz sampling, signal processing)
   - Feedback latency: < 100 ms (DSP processing, display refresh)
   - Supersonic requirement: Mandatory physics constraint
   - Indigenous content: 70-80% achievable for V1/V2

3. **Acoustic-Centered Design Insight:**
   - Unlike mechanical systems, LOMAH operates on wave physics
   - TDOA accuracy analysis replaces energy/signal budget analysis
   - Environmental compensation (temperature → V_sound) is critical
   - Sensor protection design extends lifecycle significantly

**Recommended Next Steps:**

1. Pilot installation of V1 Basic at 2 ranges for validation
2. Develop indigenous signal processing capability (DSP engineers)
3. Establish FASIT compliance testing procedure
4. Train maintenance technicians on calibration protocols
5. Plan V2 MEMS rollout based on pilot lessons learned
6. Explore MDI integration with Target UAV program
