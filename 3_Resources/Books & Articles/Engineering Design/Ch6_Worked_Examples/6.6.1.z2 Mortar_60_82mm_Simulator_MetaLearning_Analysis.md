## System Definition

> **"Súng cối (Mortar) là vũ khí bắn gián tiếp, bắn đạn theo quỹ đạo cầu vồng góc cao để tiêu diệt mục tiêu mà xạ thủ KHÔNG NHÌN THẤY. Súng cối 60mm và 82mm là vũ khí hỗ trợ hỏa lực cấp đại đội và tiểu đoàn, có thể triển khai nhanh và cung cấp hỏa lực tức thì cho bộ binh."**

**English Definition:**
> Mortars are indirect fire weapons that fire projectiles in a high-arc trajectory to engage targets the gunner CANNOT SEE. 60mm and 82mm mortars are company and battalion-level fire support weapons that can be rapidly deployed to provide immediate fire support for infantry.

### 1.5 Three Flow Types Analysis (Pahl & Beitz Framework)

| Flow Type | Real Mortar | Simulator Manifestation | Critical Parameters |
|-----------|-------------|------------------------|---------------------|
| **Material** | Round, propellant | Simulated counter | Ammo type, charge |
| **Energy** | Recoil, blast | Audio/haptic feedback | Force, timing |
| **Signal** | FDC data, FO calls | Network, display | Deflection, elevation |

**Primary Flow:** Signal (FO → FDC → Gun crew → Fire → FO observe → Adjust)

**Unique Characteristic:** Vòng lặp BẮN GIÁN TIẾP - xạ thủ không thấy mục tiêu, phải dựa vào FO và FDC!

## 3. Skill 1: Feynman Technique Analysis

### 3.1 Concept: "Indirect Fire"

#### 60-Second Explanation (ELI12)

Hãy tưởng tượng bạn ném bóng qua bức tường vào giỏ mà bạn KHÔNG NHÌN THẤY.

**Súng cối bắn gián tiếp giống như:**
- Bạn (xạ thủ) đứng bên này tường
- Giỏ (mục tiêu) bên kia tường
- Bạn không thấy giỏ!
- Nhưng có người bạn (FO) đứng trên cao, thấy cả hai
- Bạn bạn nói: "Ném xa hơn 2 mét, sang trái 1 mét"
- Bạn điều chỉnh và ném lại

**Súng cối hoạt động y vậy:**
- Xạ thủ không thấy mục tiêu
- FO (Forward Observer) nhìn thấy mục tiêu
- FDC (Fire Direction Center) tính toán
- Xạ thủ chỉ nhận số liệu và bắn
- FO quan sát, báo sửa bắn

**Tại sao khó?**
- Phải tin tưởng vào số liệu (không thấy!)
- Phải chính xác (sai 1 mil = lệch nhiều mét)
- Phải nhanh (địch di chuyển)

#### Everyday Analogy

🏠 **Ví dụ hàng ngày:** 

Giống như **đặt hàng pizza qua điện thoại**:
- **Bạn (mortar)** = Nhà bếp (nấu nhưng không biết địa chỉ)
- **FO (Forward Observer)** = Người gọi (biết địa chỉ giao)
- **FDC** = Tổng đài (nhận địa chỉ, tính đường đi)
- **Địa chỉ** = Tọa độ mục tiêu
- **Pizza giao đúng** = Đạn trúng mục tiêu

Nhà bếp không cần biết nhà khách ở đâu - chỉ cần nấu đúng và giao cho shipper đi đúng đường!

### 3.2 Concept: "Deflection and Elevation"

#### Deep Analysis (5-Layer Understanding)

**Layer 1 - Surface:** Deflection là hướng (trái/phải), Elevation là tầm (xa/gần).

**Layer 2 - Mechanism:** 
```
DEFLECTION (Hướng)         ELEVATION (Tầm)
       │                          │
       ▼                          ▼
  Left ← → Right             Low ← → High angle
       │                          │
       ▼                          ▼
  Target direction           Range to target
```

**Layer 3 - Context:**

| Setting | What it Controls | Units | Effect |
|---------|-----------------|-------|--------|
| **Deflection** | Left/right direction | Mils (6400 in circle) | Where round lands L/R |
| **Elevation** | Barrel angle | Mils (0-1600) | How far round travels |
| **Charge** | Propellant amount | Charge 1-6 | Muzzle velocity |

**Layer 4 - System:**

```
┌─────────────────────────────────────────────────────────────────────┐
│                    DEFLECTION & ELEVATION SYSTEM                     │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  DEFLECTION (Hướng - Azimuth):                                      │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │                                                              │    │
│  │                        N (0/6400)                            │    │
│  │                           │                                  │    │
│  │                           │                                  │    │
│  │            W (4800) ──────┼────── E (1600)                  │    │
│  │                           │                                  │    │
│  │                           │                                  │    │
│  │                        S (3200)                              │    │
│  │                                                              │    │
│  │  • 6400 mils = 360°                                         │    │
│  │  • 1 mil ≈ 0.056° ≈ 1m at 1000m                            │    │
│  │  • Deflection = direction mortar points                     │    │
│  └─────────────────────────────────────────────────────────────┘    │
│                                                                      │
│  ELEVATION (Tầm - Angle):                                           │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │                                                              │    │
│  │     High angle (1200+)                                      │    │
│  │          ╱                                                   │    │
│  │         ╱   ← Shorter range (same charge)                   │    │
│  │        ╱      OR longer range (higher charge)               │    │
│  │       ╱                                                      │    │
│  │      ╱                                                       │    │
│  │     ╱ Low angle (800)                                       │    │
│  │    ╱   ← Longer range (same charge)                         │    │
│  │   ╱      Flatter trajectory                                 │    │
│  │  ▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔               │    │
│  │  Ground                                                      │    │
│  │                                                              │    │
│  │  • 800 mils = 45° (minimum for mortar)                     │    │
│  │  • 1422 mils = 80° (near maximum)                          │    │
│  │  • Higher elevation = shorter range (gravity wins)         │    │
│  └─────────────────────────────────────────────────────────────┘    │
│                                                                      │
│  SIMULATION REQUIREMENT:                                             │
│  → Accurate mil conversion                                          │
│  → Show relationship between elevation and range                    │
│  → Train sight picture with bubbles                                 │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
```

**Layer 5 - Application:**

| Scenario | Deflection Change | Elevation Change | Result |
|----------|------------------|------------------|--------|
| Target left 50m | +50 mils (approx) | No change | Impact moves left |
| Target closer | No change | Increase elevation | Impact moves closer |
| Target right & far | -50 mils | Decrease elevation | Both adjustments |

### 3.3 Concept: "Fire Direction Center (FDC)"

#### Technical Deep Dive

**FDC: The Brain of Mortar Operations**

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    FIRE DIRECTION CENTER (FDC)                           │
│                    (Trung tâm Chỉ huy Hỏa lực)                          │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  WHAT FDC DOES:                                                          │
│  ┌─────────────────────────────────────────────────────────────────┐    │
│  │  INPUT:                                                          │    │
│  │  ├── Target grid coordinates (from FO)                          │    │
│  │  ├── Mortar position (known)                                    │    │
│  │  ├── Ammunition type                                            │    │
│  │  └── Met data (wind, temp, pressure)                           │    │
│  │                                                                  │    │
│  │  CALCULATION:                                                    │    │
│  │  ├── Direction: Mortar to target (azimuth)                     │    │
│  │  ├── Distance: How far to target                               │    │
│  │  ├── Charge: Which propellant for range                        │    │
│  │  └── Elevation: Angle for that distance                        │    │
│  │                                                                  │    │
│  │  OUTPUT (Fire commands):                                         │    │
│  │  ├── Deflection: 2847                                          │    │
│  │  ├── Elevation: 1156                                           │    │
│  │  ├── Charge: 3                                                  │    │
│  │  └── Rounds: 2 (adjusting)                                     │    │
│  └─────────────────────────────────────────────────────────────────┘    │
│                                                                          │
│  FDC CALCULATION METHODS:                                                │
│                                                                          │
│  METHOD 1: GRAPHICAL (Traditional)                                      │
│  ├── Plot mortar and target on map                                     │
│  ├── Measure direction with protractor                                 │
│  ├── Measure distance with scale                                       │
│  ├── Look up elevation in firing tables                               │
│  └── Time: 2-5 minutes                                                 │
│                                                                          │
│  METHOD 2: MANUAL CALCULATION                                           │
│  ├── Use formulas with grid coordinates                                │
│  ├── Solve for direction and distance                                  │
│  ├── Apply met corrections                                             │
│  └── Time: 1-3 minutes                                                 │
│                                                                          │
│  METHOD 3: COMPUTER-ASSISTED                                            │
│  ├── Enter target coordinates                                          │
│  ├── Computer solves instantly                                         │
│  ├── Accounts for all variables                                        │
│  └── Time: 10-30 seconds                                               │
│                                                                          │
│  SIMULATION REQUIREMENT:                                                 │
│  ┌─────────────────────────────────────────────────────────────────┐    │
│  │  MUST TRAIN:                                                     │    │
│  │  • Manual calculation (fundamentals)                            │    │
│  │  • Graphical method (backup)                                    │    │
│  │  • Computer-assisted (modern)                                   │    │
│  │  • Verification procedures                                      │    │
│  │  • Error checking                                               │    │
│  └─────────────────────────────────────────────────────────────────┘    │
│                                                                          │
│  ADJUSTMENT PROCEDURE:                                                   │
│  ┌─────────────────────────────────────────────────────────────────┐    │
│  │  FO observes: "Right 50, add 100"                               │    │
│  │  FDC calculates: New deflection, new elevation                  │    │
│  │  Gun receives: "Deflection 2897, Elevation 1134"               │    │
│  │  Gun fires adjusting round                                      │    │
│  │  FO observes: "Fire for effect"                                 │    │
│  └─────────────────────────────────────────────────────────────────┘    │
│                                                                          │
└─────────────────────────────────────────────────────────────────────────┘
```

### 3.4 Common Misconceptions

| Misconception | Reality | Impact on Design |
|---------------|---------|-----------------|
| "Point and shoot" | Indirect fire requires FDC | Must simulate FDC |
| "See target, aim, fire" | Gunner cannot see target | Train blind firing |
| "More charge = more range" | Correct, but also flatter | Simulate charge selection |
| "Any angle works" | Must be 45°-85° | Enforce limits |
| "One person operation" | Requires crew of 3-5 | Crew drill training |
| "Same as artillery" | Different procedures, lighter | Scale appropriately |

### 3.5 Understanding Check Questions

**Basic Recall:**
❓ Trong bắn gián tiếp, ai là người nhìn thấy mục tiêu? Xạ thủ hay FO?

**Application:**
❓ Nếu FO báo "Left 50, Add 100", FDC phải điều chỉnh Deflection và Elevation như thế nào?

**Edge Case:**
❓ Khi bắn "Danger Close" (gần vị trí quân ta), quy trình an toàn khác gì so với bắn thông thường?
