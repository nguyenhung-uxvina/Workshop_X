# SKILL 1: FEYNMAN TECHNIQUE - Simple Explanations

## 1.1 ELI12 Explanation (Explain Like I'm 12)

"Imagine you're on a boat in rough water, trying to hit a moving target with a water gun. The boat is rocking back and forth (that's roll), tipping forward and back (that's pitch), and turning left and right (that's yaw). Plus the whole boat is moving up and down (heave), sliding sideways (sway), and moving forward and back (surge).

A Naval Weapon Simulator is like a video game that teaches sailors how to use the big guns on warships. But it's not just pointing and shooting - the sailor has to tell a computer where the target is, how fast it's moving, and then the computer figures out where to aim the gun so the shell lands on the target by the time it gets there. The simulator has a moving platform that rocks like a real ship, screens that show the ocean and targets, and a fake gun station that feels like the real thing."

## 1.3 Vietnamese Terminology and Mnemonics

**"LẮC-CHÚI-XOAY-NHẤP-LẮC-TRƯỢT"** (6-DOF Memory):
```
LẮC (ngang)  = Roll  = Rotation around X
CHÚI (dọc)   = Pitch = Rotation around Y
XOAY (mũi)   = Yaw   = Rotation around Z
NHẤP (nhô)   = Heave = Translation along Z
LẮC (dọc)    = Surge = Translation along X
TRƯỢT (ngang)= Sway  = Translation along Y
```

**"TÌM-BÁM-TÍNH-BẮN"** (Find-Track-Compute-Fire):
```
TÌM   → Target acquisition (radar, visual)
BÁM   → Target tracking (maintain lock)
TÍNH  → Ballistic computation (lead, wind, motion)
BẮN   → Fire control (weapon laying, fire)
```

**"MỤC-VẬN-GIÓ-TÀU-ĐẠN"** (Solution Components):
```
MỤC   → Target position
VẬN   → Target velocity → lead angle
GIÓ   → Wind and atmosphere correction
TÀU   → Ship motion compensation
ĐẠN   → Ballistic trajectory
```

# SKILL 12: TARGETED DRILL MASTER

## 12.1 Drill A: Ship Motion Calculation

**Problem**: Gepard-class frigate (L=102m, B=13m) in Sea State 4 (Hs=2.0m). Estimate roll amplitude.

**Formula**: Roll ≈ k × Hs × (B/L)^0.5 where k ≈ 12

**Solution**:
```
Roll = 12 × 2.0 × (13/102)^0.5 = 12 × 2.0 × 0.357 = 8.6°
Roll period ≈ 0.8 × B^0.5 = 0.8 × 13^0.5 = 2.9 seconds

RESULT: ±8.6° roll at ~0.3 Hz
Platform requirement: ±10° minimum
```

## 12.2 Drill B: Lead Angle Computation

**Problem**: Aircraft crossing at 250 m/s, range 3000m, muzzle velocity 925 m/s.

**Solution**:
```
t_flight = R / V_m = 3000 / 925 = 3.24 seconds
d_target = V_t × t = 250 × 3.24 = 810m
θ_lead = arctan(810 / 3000) = 15.1° = 269 mils
```
