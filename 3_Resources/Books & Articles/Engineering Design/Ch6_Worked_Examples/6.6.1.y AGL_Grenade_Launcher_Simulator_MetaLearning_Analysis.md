## System Definition

> **"Súng phóng lựu tự động (Automatic Grenade Launcher - AGL) là vũ khí tổ đội bắn liên thanh đạn 40mm, có khả năng tiêu diệt mục tiêu diện tích, công sự nhẹ, và phương tiện không bọc thép. Các hệ thống tiêu biểu bao gồm MK19 (Mỹ), AGS-17/30 (Nga), và Mk47 Striker. Huấn luyện thật rất đắt do giá đạn 40mm ($30-50/viên) và yêu cầu thao trường đặc biệt."**

**English Definition:**
> Automatic Grenade Launchers (AGL) are crew-served weapons firing 40mm grenades in automatic mode, capable of engaging area targets, light fortifications, and unarmored vehicles. Representative systems include MK19 (USA), AGS-17/30 (Russia), and Mk47 Striker. Live training is expensive due to 40mm grenade costs ($30-50/round) and special range requirements.

| Chức năng chính | Mô tả | Người dùng mục tiêu |

| **Nạp đạn** | Quy trình dây đạn | Phụ tải đạn |

### 1.5 Three Flow Types Analysis (Pahl & Beitz Framework)

| Flow Type | Real AGL | Simulator Manifestation | Critical Parameters |
|-----------|----------|------------------------|---------------------|
| **Material** | Belt ammunition, links | Simulated counter, belt motion | Ammo count, feed |
| **Energy** | Recoil impulse, cycling | Pneumatic/CO₂ feedback | Force (N), timing |
| **Signal** | Sight picture, impact | Display, trajectory viz | Latency, accuracy |

**Primary Flow:** Energy (Trigger → Firing mechanism → Recoil → Belt advance → Next round)

**Unique Characteristic:** Đường đạn 40mm có quỹ đạo CONG RÕ RỆT - phải mô phỏng chính xác!

### 2.4 40mm Ballistics - The Curved Trajectory

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    40MM BALLISTICS: THE "LOB"                            │
│                    (Understanding Curved Trajectory)                     │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  KEY INSIGHT: 40mm grenades travel SLOWLY (240 m/s vs 920 m/s rifle)   │
│  → Results in highly curved, "lobbing" trajectory                       │
│  → Must aim ABOVE target for range                                      │
│  → Can see rounds in flight!                                            │
│                                                                          │
│  TRAJECTORY COMPARISON (to 1000m target):                               │
│                                                                          │
│       5.56mm Rifle (920 m/s)                                            │
│       ═══════════════════════════════════════════════════► Target      │
│       (Nearly flat, drop ~3m)                                           │
│                                                                          │
│       40mm Grenade (240 m/s)                                            │
│                    ⌒⌒⌒                                                  │
│                 ⌒      ⌒                                                │
│              ⌒          ⌒                                               │
│           ⌒              ⌒                                              │
│         ⌒                  ⌒                                            │
│       ═                      ⌒⌒⌒⌒⌒► Target                             │
```

## 3. Skill 1: Feynman Technique Analysis

### 3.1 Concept: "Automatic Grenade Launcher"

#### 60-Second Explanation (ELI12)

Hãy tưởng tượng một khẩu súng bắn... lựu đạn! Không phải lựu đạn ném tay, mà là lựu đạn nhỏ bắn ra như đạn súng máy.

**Súng phóng lựu tự động** giống như:
- **Súng máy** (bắn liên thanh, dây đạn)
- **+** **Lựu đạn** (nổ khi trúng, mảnh văng)
- **=** Bắn liên thanh lựu đạn!

**Đặc biệt:**
- Đạn bay CHẬM (240 m/s thay vì 900 m/s)
- Nên đường đạn CONG như ném bóng
- Phải ngắm CAO hơn mục tiêu
- Có thể THẤY đạn bay (tracer)
- Nổ khi trúng, diệt cả vùng

**Dùng để làm gì?**
- Diệt bộ binh ẩn nấp
- Phá công sự nhẹ
- Phục kích xe không bọc thép
- Bắn vào khu vực (không cần bắn trúng điểm)

#### Everyday Analogy

🏠 **Ví dụ hàng ngày:** 

Giống như **máy bắn bóng tennis tự động + bóng nổ pháo hoa**:
- **Máy bắn bóng** = Súng phóng lựu (bắn liên tục)
- **Bóng tennis** = Đạn 40mm (bay cong, chậm)
- **Bóng nổ pháo hoa** = Nổ khi chạm đất
- **Điều chỉnh góc** = Điều chỉnh tầm bắn
- **Xem bóng rơi** = Quan sát đạn rơi, sửa bắn

Khác với súng trường (như bắn đạn thẳng tắp), AGL bắn "vòng cung" như ném bóng.

### 3.2 Concept: "Adjustment Fire" (Sửa Bắn)

#### Deep Analysis (5-Layer Understanding)

**Layer 1 - Surface:** Sửa bắn là điều chỉnh ngắm dựa trên quan sát đạn rơi.

**Layer 2 - Mechanism:** 
```
FIRE → OBSERVE → ANALYZE → ADJUST → FIRE AGAIN
  ↓        ↓         ↓         ↓          ↓
Burst   Impact   Short/Over  Range drum  For effect
```

**Layer 3 - Context:**

| Observation | Meaning | Adjustment |
|-------------|---------|------------|
| Impact SHORT of target | Range too short | ADD range on drum |
| Impact OVER target | Range too long | SUBTRACT range |
| Impact LEFT | Off direction | Traverse RIGHT |
| Impact RIGHT | Off direction | Traverse LEFT |
| No impact visible | Wrong area/dead space | Major adjustment |

**Layer 4 - System:**

```
┌─────────────────────────────────────────────────────────────────────┐
│                    ADJUSTMENT FIRE TECHNIQUE                         │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  METHOD 1: BRACKETING                                                │
│  ├── Fire long (over target)                                        │
│  ├── Fire short (under target)                                      │
│  ├── Split the difference                                           │
│  └── Fire for effect                                                │
│                                                                      │
│  METHOD 2: CREEPING (preferred for slow approach)                   │
│  ├── Start short deliberately                                       │
│  ├── Add range incrementally (50-100m)                             │
│  ├── "Walk" fire onto target                                       │
│  └── Less ammo waste, safer for friendlies                         │
│                                                                      │
│  METHOD 3: AREA FIRE (for multiple targets)                         │
│  ├── Establish impact in target area                               │
│  ├── Traverse across area                                          │
│  ├── Maintain range setting                                        │
│  └── Cover entire kill zone                                        │
│                                                                      │
│  SIMULATION REQUIREMENT:                                             │
│  → Show impact with realistic delay                                 │
│  → Display visible dust/smoke at impact                            │
│  → Allow range drum adjustment                                     │
│  → Track rounds fired vs hits                                      │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
```

**Layer 5 - Application:**

| Scenario | Recommended Technique | Simulator Training |
|----------|----------------------|-------------------|
| Single point target | Bracketing | Mode 4 |
| Area target (troops) | Area fire | Mode 5 |
| Approaching friendlies | Creeping | Mode 4 Advanced |
| Vehicle | Rapid bracket | Mode 5 |
| Defilade | High angle adjust | Mode 6 |

### 3.4 Common Misconceptions

| Misconception | Reality | Impact on Design |
|---------------|---------|-----------------|
| "Aim like a rifle" | AGL requires super-elevation for range | Must simulate curved trajectory |
| "Point and shoot" | Requires adjustment fire | Must show impacts with delay |
| "One person operation" | Crew-served weapon | Simulate crew coordination |
| "Same as mortar" | Direct fire, not indirect | Different sighting, lower angle |
| "Recoil like rifle" | Much heavier, slower cycling | Different recoil pattern |
| "Instant hit" | 5+ seconds TOF at range | Realistic delay essential |
