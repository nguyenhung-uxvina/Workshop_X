## Executive Summary

### Project Context

The **LOMAH System** (Location of Miss and Hit - Hệ thống Định vị Trúng/Trượt) is an **acoustic scoring system** that provides real-time, precise XY coordinates of bullet impacts for live-fire marksmanship training. Unlike paper targets requiring manual inspection, LOMAH delivers **instant feedback** by detecting the shock wave (Mach cone) of supersonic projectiles passing through a sensor array.

**System Classification: SIGNAL-DOMINANT (Acoustic Measurement Device)**

The LOMAH system's primary function is **converting acoustic signals into position data** - making it fundamentally a SIGNAL-dominant system where the shock wave detection and TDOA (Time-Difference-of-Arrival) calculation IS the product.

### Key Independence Problem: P ↔ F

| Parameter | Symbol | What It Means | Why Independent? |
|-----------|--------|---------------|------------------|
| **Position Accuracy** | P | XY coordinate precision (mm) | Training value depends on precise feedback |
| **Fire Mode** | F | Single shot vs automatic burst | Must score both equally well |

**The P ↔ F Independence Problem**:
- Single shot: Clear shock wave, all sensors contribute, high P
- Burst fire: Overlapping shock waves (5-10ms apart), interference, reduced P
- **Solution**: Parallel processing channels + wave separation algorithms = INDEPENDENT accuracy

## Step 2: Essential Problem Abstraction

> **Detect supersonic projectile passage through a defined target area, calculate precise XY impact coordinates using acoustic TDOA, and display results in real-time, with INDEPENDENT ACCURACY for both single shots and automatic fire bursts.**

### Key Physics

**Speed of Sound**:
```
V_sound = 331.3 × √(1 + T/273.15) m/s
At 20°C: V_sound = 343.2 m/s
```

**TDOA Positioning**:
```
Δt_ij = (d_i - d_j) / V_sound
With 4 sensors → 3 independent equations → Solve for (X, Y)
```

**Mach Cone**:
```
sin(θ) = V_sound / V_bullet = 1/M
For 5.56mm at 900 m/s: θ ≈ 22.6°
```

```
DETECTION SUBSYSTEM:

[MIC 4]──►[PREAMP]──►[ADC]──►┘

PROCESSING SUBSYSTEM:
[SHOT DETECTOR]──►[WAVE SEPARATOR]──►┌──►[TDOA Calc 1]──►┐
                                     ├──►[TDOA Calc 2]──►│
                   Parallel          ├──►[TDOA Calc 3]──►├──►[RESULTS]
                   pipelines         └──►[TDOA Calc 4]──►┘

OUTPUT SUBSYSTEM:
[RESULTS QUEUE]──►[3D→2D PROJECTION]──►[DISPLAY RENDER]
       │                                      │
[FASIT INTERFACE]──►[Range Control System]   │
```

**Selection Rationale**:
- TRUE P-F independence through parallel channels
- Handles 1200 rpm without accuracy loss
- Wave separation for overlapping shock waves
- Scalable architecture

## 13-Skill Meta-Learning Applications

### Skill 1: Feynman Technique

**ELI12 Explanation**: LOMAH is like having four super-sensitive ears around the target. When a bullet flies by faster than sound, it makes a tiny "sonic boom." The four microphones hear this boom at slightly different times - maybe one ear hears it 3 millionths of a second before another. A computer uses these tiny time differences to figure out EXACTLY where the bullet passed through - and tells you instantly!

### Skill 7: Vietnamese Mnemonics

**System**: "NGHE-ĐO-TÍNH-HIỆN" (Listen-Measure-Calculate-Display)
- Nghe = Listen (detect shock wave)
- Đo = Measure (arrival times)
- Tính = Calculate (TDOA math)
- Hiện = Display (show results)

**Independence**: "CHÍNH-XÁC-ĐỒNG-NHẤT" (Accurate-Same-Uniform)
- "Chính xác đồng nhất, đơn phát hay liên thanh đều như một"
- (True and uniform accuracy, single shot or burst all the same)

### Skill 9: Systems Mapping

**Key Loops**:
- R1: Instant Feedback → Faster Learning → Better Marksmen → More Training Value (reinforcing)
- B1: More Channels → More Complexity → Lower MTBF (balancing)

**Leverage Points**:
- L10: Parallel processing STRUCTURE enables P-F independence
- L11: High-speed sampling BUFFER provides timing margin
