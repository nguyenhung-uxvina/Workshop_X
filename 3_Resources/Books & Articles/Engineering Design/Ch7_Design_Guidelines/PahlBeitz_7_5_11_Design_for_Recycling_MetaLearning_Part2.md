## 12. Skill 11: Engineering-Self-Assessment-Rubric-Generator

### DfR Self-Assessment Rubric

**Artifact:** Recycling Strategy Document for Defense System

| Criterion | Weight | 0 - Needs Work | 1 - Developing | 2 - Proficient | 3 - Exemplary |
|-----------|--------|----------------|----------------|----------------|---------------|
| **Strategy Selection** | HIGH | No strategy | Mentioned, not justified | Selected + rationale | + alternatives compared |
| **Material Inventory** | HIGH | No list | <50% materials | All listed | + compatibility analysis |
| **Interface Design** | HIGH | Permanent bonds | Some separable | All major designed | + disassembly sequence |
| **Preprocessing Plan** | MEDIUM | Not considered | General method | Specific per assembly | + validated with recycler |
| **Reconditioning** | MEDIUM | Not considered | Partial assessment | Full + procedures | + cost-benefit |
| **VDI 2221 Integration** | MEDIUM | DfR afterthought | In embodiment | From conceptual | + drives concepts |
| **Documentation** | LOW | None | Basic labels | Full manual | + training materials |
| **Hazmat Handling** | HIGH | Embedded | Separable | Easy + documented | + disposal procedure |

### Score Calculation

```
Score = Σ (Weight × Score) / Σ (Weight × 3)

Weight values: HIGH = 3, MEDIUM = 2, LOW = 1

Interpretation:
• 86-100%: EXEMPLARY - Ready for production release
• 61-85%:  PROFICIENT - Minor improvements needed
• 41-60%:  DEVELOPING - Major gaps to address
• 0-40%:   NEEDS WORK - Return to fundamentals
```

### Drill Set 2: Material Compatibility Analysis

**Duration:** 30 minutes | **Difficulty:** ⭐⭐⭐

**Problem:** The Radar-IR Target Simulation pod contains:

| Component | Material |
|-----------|----------|
| Outer shell | Aluminum 6061-T6 |
| Internal frame | Steel 1018 |
| Heat sink | Copper C11000 |
| Connectors | Brass (Cu-Zn) |
| Fasteners | Stainless Steel 304 |

**Identify problematic combinations for shredding:**

1. **Cu heat sink + Al shell** → Cu contaminates Al
2. **Brass connectors + Al shell** → Same Cu problem
3. **Steel frame + SS fasteners** → Ni/Cr complicates steelmaking

## 16. Vietnamese Context Adaptations

### Local Recycling Infrastructure

| Material Type | Vietnamese Capability | Design Implication |
|---------------|----------------------|-------------------|
| Steel | Strong - multiple mills | Design for steel group compatibility |
| Aluminum | Moderate - secondary smelters | Separate from Cu; compatible alloys |
| Copper | Strong - high demand | Design for easy Cu recovery |
| Electronics | Developing - specialists emerging | Easy PCB removal; label |
| Plastics | Weak - PE, PP, PET only | Single type; avoid mixed |
| Composites | Very weak - no domestic | Minimize use; design for repair |
| Batteries | Emerging - specialist services | Easy battery module removal |

### Appendix B: Material Compatibility Tables

#### Steel Compatibility Groups

| Group | Acceptable Alloys | Contaminants to Avoid |
|-------|-------------------|----------------------|
| Unalloyed Steel | 1018, 1020, 1045, 4140 | Cu >0.4%, Pb >0.05% |
| Low-Alloy Steel | 4130, 4140, 4340, 8620 | Ni >0.5%, Cr >0.5% |
| Stainless Steel | 304, 316, 410, 430 | Carbon steel |
| Tool Steel | D2, M2, A2 | Other steel types |

#### Aluminum Compatibility Groups

**Connections to AVOID:**

- Welding → Use bolted joint
- Rivets → Use bolts or quarter-turn
- Permanent press-fit → Use slip-fit + retention
- Overmolding → Use snap-fit assembly
