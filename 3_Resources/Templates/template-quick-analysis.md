## 1-MINUTE SCAN: What level are we at?

Check the box for current thinking:

- [ ] **L12-L10 thinking**: "We need more budget/people/equipment"
- [ ] **L9-L7 thinking**: "We need to fix the process/timing"
- [ ] **L6-L4 thinking**: "We need better information/rules/adaptation"
- [ ] **L3-L1 thinking**: "We need to change goals/paradigms"

**Reality check**: Most problems are L3-L6. If you checked L12-L10, keep reading.

## DECISION TREE:

```
START: Problem identified
  |
  ├─ Is goal misaligned? (L3)
  |    YES → Fix goal first
  |    NO ↓
  |
  ├─ Are rules wrong? (L5)
  |    YES → Change rules/incentives
  |    NO ↓
  |
  ├─ Is information missing? (L6)
  |    YES → Fix information flow
  |    NO ↓
  |
  ├─ Are feedback loops wrong? (L7-L9)
  |    YES → Adjust loops/delays
  |    NO ↓
  |
  └─ Is physical constraint? (L10-L12)
       YES → Consider infrastructure change
```

---

## RED FLAGS (You're going low-leverage):

- [ ] First response is "hire more people"
- [ ] Talking about new equipment/software before process
- [ ] Adjusting numbers without questioning what they measure
- [ ] Adding buffers without fixing root cause
- [ ] "We tried everything" (but all L12 tweaks)

**If 2+ boxes checked**: STOP. Climb the hierarchy. Start with L3-L6.

---

## QUICK WINS (Usually L5-L6):

These are often fast, cheap, high-impact:

1. **Change one rule** that drives wrong behavior
2. **Make one thing visible** that was hidden
3. **Remove one approval** that causes delay
4. **Change one metric** that gets gamed
5. **Connect one person** to their impact

Pick ONE. Do it this week. See what happens.

---

## LEARNING TRIGGER:

Schedule 2-week review:
- [ ] Did intervention work?
- [ ] If yes, why? (What leverage point did we actually hit?)
- [ ] If no, what did we learn? (Go higher in hierarchy?)
- [ ] What unintended consequences?
