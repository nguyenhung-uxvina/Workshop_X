## 2. KEY FINDINGS

### 2.1 Essential AAR Metrics for C-UAV / USV Gunnery Training

**★★★ HIGH confidence — confirmed by Tier S + A sources**

**Engagement-level metrics (per shot / per burst):**
- **Hit/Miss classification** — binary outcome per engagement, recorded with timestamp
- **Miss distance** — lateral and vertical deviation from aimpoint (mm or mrad at range)
- **Time-to-first-shot (TTFS)** — from target detection to first trigger pull (seconds)
- **Reaction time** — from target presentation to first engagement action
- **Lead angle accuracy** — angular error between shooter's predicted intercept point and actual ballistic solution (critical for moving C-UAV/USV targets)
- **Engagement time** — duration from first shot to cease fire or kill confirmation
- **Shot dispersion (CEP)** — circular error probable of shot group (radius containing 50% of rounds)
- **Burst efficiency** — rounds expended per kill / per engagement
- **Weapon cant** — roll angle of weapon at moment of firing (degrees)
- **Trigger pull characteristics** — duration, pressure profile, smoothness

**Session-level metrics (per training session):**
- **Hit probability (Pk)** — number of hits / total rounds fired (or kills / total engagements)
- **Mean TTFS ± σ** — consistency of reaction time
- **Ammunition expenditure per kill**
- **Friendly-fire incidents** (if multi-target scenario)
- **Target type breakdown** — Pk per target category (UAV size class, speed, approach angle)
- **Performance trend** — current session vs. historical baseline (delta)

**For naval C-UAV / USV specifically:**
- **Bearing rate tracking error** — how well the gunner tracks a crossing target
- **Elevation angle engagement window** — time within which target was in valid firing solution
- **Lead angle error** — difference between aim point and correct ballistic intercept point (patent US4781593A directly addresses this)
- **Engagement initiation angle** — bearing angle at which first shot was fired (early = better)
- **Multi-target sequence time** — time to engage sequential targets

### 2.2 Coaching Algorithm Approaches — InVeris/FATS/SCATT and Industry

**★★★ HIGH — Tier S (Patent WO2015142940) + Tier A (InVeris) + Tier A (SCATT)**

**InVeris BlueFire / FATS Automatic Coaching (patent-pending as of 2015):**

Architecture (from WO2015142940A1 — Meggitt):
1. **Data collection layer:** Weapon-mounted sensors capture:
   - Trigger squeeze pressure + timing profile
   - Buttstock pressure (left-right, up-down)
   - Weapon cant (roll angle via IMU)
   - Aim trace (muzzle position trajectory vs. time, via optical sensor or IMU)
   - Shot timestamp
2. **Reference database:** Library of "good" and "bad" example shot profiles (training data for classifier)
3. **Classification engine:** Evaluation function trained on labeled examples classifies each shot as good/bad per parameter
4. **Error attribution:** System identifies which fundamental is violated:
   - Trigger jerk: rapid pressure spike just before sear break → visible as abrupt aim trace deflection
   - Flinch: involuntary movement in anticipation of recoil → trace drift away from hold area in last 200ms
   - Cant: non-zero roll at moment of firing
   - Butt pressure error: inconsistent cheekweld pressure
   - Breathing: firing outside respiratory pause window
5. **Feedback delivery:** Tablet-based display of shot trace, error flag, doctrinal correction text + video clip

**SCATT (Tier A — commercial precision shooting trainer):**
- Optical sensor on barrel tracks muzzle position vs. target at up to 200 Hz
- Metrics output:
  - **S1 score** — trace speed 1 second before shot (mm/s) — world-class: 20–40mm/s range
  - **Shot hole location** — actual impact relative to hold point
  - **Trace visualization** — full aim path displayed on target overlay
  - **Trigger flinch indicator** — detected when trace shows sudden deflection in final 100–200ms before shot
  - **Heartbeat interval analysis** — graph of velocity spikes corresponding to cardiac pulse
- SCATT provides direct comparison to reference shooter's trace pattern

**Key algorithm insight for C-UAV system:** For a moving target (UAV/USV), the "aim trace" metric becomes "tracking error rate" — the distance between the weapon's instantaneous aim point and the target's real-time position. Good tracking = small, consistent tracking error before trigger pull.

## 3. RECOMMENDED SCORING ALGORITHM — RAY-TRACE BASED SYSTEM

**★★★ HIGH — synthesized from Tier S: Virtual Ballistic Projectile Simulation paper + DTIC CEP report + Patent US20120183931**

### 3.1 Architecture Overview

```
INPUT: Weapon state at T_fire
  - Muzzle position (x, y, z)
  - Barrel direction vector (azimuth, elevation)
  - Target position + velocity vector at T_fire
  - Ammo type (determines ballistic model parameters)

STEP 1: BALLISTIC TRAJECTORY MODEL
  - Compute deterministic trajectory (gravity drop + drag)
  - Apply CEP dispersion: generate N stochastic shot samples
    using bivariate Gaussian distribution centered on nominal aim
  - Each sample = one possible actual round trajectory

STEP 2: RAY-TARGET INTERSECTION
  - For each sample trajectory, cast ray through time-stepped simulation
  - Check intersection with target bounding volume at each timestep
  - Account for target movement during time-of-flight (TOF)
  - Hit = ray intersects target volume within TOF window

STEP 3: HIT PROBABILITY (Pk) CALCULATION
  Method A (Monte Carlo): Run N=1000+ samples → Pk = hits/N
  Method B (Analytical): Use Gaussian Pk formula
    Pk = 1 - exp(-0.5 × (miss_distance/σ)²)
    where σ = CEP / 1.1774 (for circular normal distribution)
  
  For moving targets: apply "Detached-Displacement" correction
    - Compute target displacement during TOF
    - Offset nominal intersection point by displacement vector
    - This is the key finding of the Figshare synthetic hit algorithm paper

STEP 4: HIT/MISS CLASSIFICATION
  Per-shot classification:
    - If miss_distance < target_lethal_radius → HIT
    - If miss_distance < target_damage_radius → NEAR_MISS (partial damage)
    - Otherwise → MISS
  
  Score per shot:
    - HIT = full score (1.0)
    - NEAR_MISS within 0.5×radius → partial score (0.5)
    - MISS with miss_distance < 2×radius → "close" (logged for coaching)
    - MISS with miss_distance > 5×radius → "far miss" (fundamental error)

STEP 5: SESSION PK AGGREGATION
  Pk_session = Σ(hits) / Σ(engagements)
  Pk_by_target_type[UAV_small] = ...
  Pk_by_range_band[200m-400m] = ...
  Pk_trend = Pk_session - Pk_baseline (trainee historical average)
```

### 3.4 Ray-Trace vs. Laser/IR Detection — Comparison

| Criterion | Ray-Trace (software) | Laser/IR (hardware) |
|-----------|---------------------|---------------------|
| Accuracy | Sub-mm at any range, ballistically correct | Physical beam, 1–3mm at screen, affected by ambient IR |
| Moving target | Corrected by TOF model (detached-displacement) | Instant — no TOF correction possible |
| Ballistic modeling | Full (gravity drop, wind, dispersion, CEP) | None — laser is straight-line only |
| Cost | Negligible (CPU compute) | Hardware per weapon: $2K–$10K+ |
| Indoor use | Any | Requires controlled IR environment |
| Multi-weapon | Trivially scalable | Each weapon needs IR emitter |
| Realism for C-UAV | HIGH — models actual bullet flight to moving target | LOW — straight-line laser cannot model lead angle physics |
| **Verdict for VN-12.7MM-SIM** | **Preferred** | Not recommended for moving target gunnery |

**Key insight:** For C-UAV/USV gunnery where targets move at 20–150 km/h, ray-trace ballistic simulation is the ONLY approach that can teach and score lead angle correctly. Laser/IR physically cannot model TOF-dependent intercept geometry.

## 5. ADAPTIVE DIFFICULTY — EVIDENCE-BASED APPROACH

**★★★ HIGH — IEEE papers + PMC empirical study + Springer simulation flight training**

### 5.1 Theoretical Framework

**Combine two principles:**
1. **Zone of Proximal Development (ZPD, Vygotsky):** Trainee should operate at tasks slightly beyond current unassisted capability — not too easy (boredom), not too hard (anxiety/overload)
2. **Flow Theory (Csikszentmihalyi):** Optimal learning occurs when challenge ≈ skill. The "Zones of Proximal Flow" framework integrates both — target the zone where challenge exceeds current skill by a calibrated margin

**Empirical result (submarine training study, Tier B):** Adaptive difficulty produced 46% reduction in errors and 49% improvement in accuracy vs. fixed-difficulty training.

### 5.2 Performance State Machine

Define trainee state based on rolling Pk window (last N engagements):

```
STRUGGLING:   Pk < 30% over last 10 engagements
DEVELOPING:   Pk 30–60%
PROFICIENT:   Pk 60–80%
EXPERT:       Pk > 80%
```

### 5.3 Difficulty Parameters to Adjust

For C-UAV / USV gunnery simulator:

| Parameter | STRUGGLING | DEVELOPING | PROFICIENT | EXPERT |
|-----------|-----------|-----------|-----------|--------|
| Target speed | 20 km/h | 40 km/h | 80 km/h | 120+ km/h |
| Target size (RCS proxy) | Large drone | Medium | Small | Micro-UAV |
| Approach angle | Head-on (0°) | 30° crossing | 90° crossing | Oblique |
| Number of targets | 1 | 1–2 | 2–3 | 3–4 sequential |
| Engagement window (time) | 30s | 20s | 12s | 8s |
| Target evasive maneuver | None | Mild | Moderate | Aggressive |
| Target altitude variation | None | ±5m | ±20m | ±50m |
| Background clutter | Clear | Low | Moderate | High |

### 5.4 Adaptation Algorithm

```python
# Pseudocode — runs after each engagement

def adapt_difficulty(trainee):
    pk_rolling = compute_rolling_pk(trainee, window=10)
    
    if pk_rolling < 0.30:
        # Struggling — reduce difficulty
        difficulty = max(difficulty - 1, DIFFICULTY_MIN)
        flag = "REDUCE — trainee below threshold"
    
    elif pk_rolling > 0.75 and consecutive_hits >= 5:
        # Proficient — increase difficulty
        difficulty = min(difficulty + 1, DIFFICULTY_MAX)
        flag = "INCREASE — trainee exceeds target Pk"
    
    else:
        # In ZPD — maintain current level
        flag = "MAINTAIN — trainee in flow zone"
    
    log_adaptation(trainee, pk_rolling, difficulty, flag)
    apply_scenario_parameters(difficulty)
    return difficulty
```

**Between-session adaptation (stronger signal):**
- Use full session Pk + TTFS trend to set starting difficulty for next session
- If previous session ended at PROFICIENT → next session starts at PROFICIENT level
- If trainee regresses across 2 sessions → drop one level + notify instructor

### 5.5 Adaptive AI for Target Behavior (Tier S — IEEE papers)

Two approaches from literature:

**Approach 1: Behavior-Based Scaling**
- Target AI has N difficulty parameters (speed, evasion, exposure time)
- Each is a continuous variable mapped to [0, 1]
- DDA controller adjusts variables based on trainee Pk in real time
- Source: "Dynamic Game Difficulty Scaling Using Adaptive Behavior-Based AI" (IEEE 5783334)

**Approach 2: Imitation + Adversarial (Tier S — arXiv 2408.06818)**
- Agent 1 learns to imitate the trainee's shooting behavior
- Agent 2 (target) trains against Agent 1 → finds optimal evasion strategy for that specific trainee
- At intervals, deploy Agent 2 as the actual target → personalized challenge
- Most sophisticated approach — requires RL infrastructure but produces truly personalized difficulty

**Recommended for VN-12.7MM-SIM Phase 1:** Approach 1 (behavior-based scaling) — simpler to implement, well-validated, deterministic and explainable. Reserve Approach 2 for Phase 2+ when trainee database is sufficiently populated.
