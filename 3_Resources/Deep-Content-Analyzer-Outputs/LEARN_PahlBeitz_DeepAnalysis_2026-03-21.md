## Three Laws (CEO Validated)

### 1. Abstraction-Gate Law
Ai skip abstraction sẽ thiết kế brilliantly cho bài toán sai. 5-step abstraction = cơ chế duy nhất phá solution bias. FM-1 = failure mode #1.

### 2. Loop-Size Law
Within-phase iteration = refinement (good). Cross-phase backward iteration = catastrophe (months wasted). Front-loading converts cross→within.

### 3. Solution-Determining Subfunction Law
1 subfunction quyết định toàn bộ design downstream. Identify trước, giải quyết trước. Decompose deep ở đó, shallow ở rest.

## 7 Core Principles (from analysis)
P1: Abstraction Before Solution
P2: Function is Transformation, Not Technology
P3: Technical/Economic/Safety = Non-Negotiable Triad
P4: Demands (binary knockout) ≠ Wishes (scalar scoring)
P5: Iteration expected — loop SIZE determines outcome
P6: Concurrent Evaluation, Not End-Gate
P7: Function Structure = design decision, not discovery

## System Archetypes
- R1: Solution Lock-in Loop (skip abstraction → familiar solutions → biased criteria → skip abstraction)
- R2: Requirement Inflation Loop (add reqs → shrink space → marginal concepts → add more reqs)
- R3: Front-Loading Compound Return (invest early → smaller loops → faster later → more investment)
- B1: Abstraction-Constraint Balance (too abstract = infinite search, too specific = narrow)
- B2: Decomposition Depth Balance (too shallow = complex SFs, too deep = wasted precision)
- D1: Physical Embodiment Delay (concept→embodiment incompatibility discovery)
- D2: Customer Feedback Delay (requirements set→design→customer sees results)

## Top 5 Failure Modes
FM-1: Solution Bias — jump to solution, justify backward
FM-2: D/W Confusion — treat all as demands (paralysis) or all as wishes (chaos)
FM-3: Over-Decomposition — original-design decomposition applied to adaptive design
FM-4: 60% Threshold Violation — advance weak concepts, ignore value profile weak spots
FM-5: Sequential Delusion — treat embodiment 15 steps as Gantt chart, not iterative checklist

## Hidden Assumptions (when P&B fails)

A4: Team has domain knowledge (fails in new-to-domain situations)
