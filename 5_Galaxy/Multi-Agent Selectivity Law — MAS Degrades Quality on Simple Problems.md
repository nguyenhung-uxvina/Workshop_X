## Y Tuong Cot Loi

Multi-agent collaboration CHI tot hon single-agent tren bai toan PHUC TAP, COUPLED, DAI HAN. Tren bai toan don gian, ngan, khong coupled — MAS GIAM chat luong vi overhead coordination lan at thoi gian thuc hien. Ap dung multi-agent selective, khong blanket.

## Giai Thich Chi Tiet

Evidence tu SBCE simulation + LLM MAS studies:
- **Simple/uncoupled problems:** MAS chia effort qua mong, khong du thoi gian optimize bat ky solution nao. Single expert tap trung 100% effort → ket qua tot hon.
- **Short-timespan tasks:** SBCE giu nhieu sets = moi set underdeveloped. Point-based = 1 set fully developed.
- **Strict logic tasks:** Faulty agent inject semantic error → cascading through chain → 22.6% perf drop.

**Khi nao MAS tot hon:**
- Complex coupled problems (Mech × Elec × SW interactions)
- Long development timeline (du thoi gian explore + narrow)
- Cross-domain integration challenges (coupling analysis, CFMA)
- Original/RED complexity designs (new product class)

**Khi nao KHONG dung MAS:**
- GREEN complexity (variant-level, WX has prior art)
- Validation/preflight checks (simple gate, khong can debate)
- CEO decision points (non-delegable, 1 authority)
- Detail calculations (1 expert + verification > debate)

## Tai Sao Dieu Nay Quan Trong?

- Tranh "multi-agent everywhere" trap — overhead > benefit tren simple tasks
- HELIX block selection: BB (Search) + BD (Risk) = YES. B0 (Preflight) + BE (Select) = NO.
- RE Complexity classification (GREEN/AMBER/RED) quyet dinh co dung MAS hay khong
- WX CEO time la binding constraint — khong lang phi vao unnecessary coordination
