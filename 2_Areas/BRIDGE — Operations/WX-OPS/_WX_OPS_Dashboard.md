# WX-OS — Workshop X AI-First Operations System

> **Architecture:** 4-layer AI-First (Data → Workflow → Intelligence → CEO Command). See [[WX-OS_Architecture_v1.0]].
> **Pattern:** CSV + Markdown + Claude Code skills + AI Intelligence Layer.
> **Users:** CEO primary (Phase 1). Staff input planned Phase 3.
> **Migration path:** ERPNext-compatible CSV → import when ready.
> **AI-First Principle:** System THINKS, not just STORES.

## AI Intelligence Layer

Khi gọi `/ops` (không args), AI tự động chạy 4 algorithms và tạo briefing:

| Algorithm | Input | Output |
|-----------|-------|--------|
| Material Availability | BOM × WOs × Stock | ✅ ĐỦ / ⚠️ VỪA / ❌ THIẾU per item |
| PX Capacity Heatmap | WOs × Routing | 🟢 <50% / 🟡 50-80% / 🔴 >80% per PX |
| Delay Prediction | WOs × Routing × Queue × Material | ✅ On track / ⚠️ At risk / 🔴 Late |
| Reorder Alert | Stock × BOM demand × WO targets | 🔴 BLOCKING / 🟡 LOW / ✅ OK |

**Compound Learning:** Sau ≥5 WOs completed cho cùng product → so sánh actual vs planned lead time → suggest routing update.

## Quick Commands

```
/ops                         → AI BRIEFING (production + stock + capacity + delays)
/ops production              → WO dashboard + delay predictions + capacity heatmap
/ops production add          → Create WO + mandatory material availability check
/ops production update WO-ID → Update status + cascade effects
/ops production log          → Log daily production activity (5 min end-of-day)
/ops inventory               → Stock levels + reorder alerts cross-ref with WOs
/ops inventory check ITEM    → Check item + which WOs need it
/ops inventory po            → Create PO (priority-ranked by production impact)
/ops finance                 → Monthly P&L, cash flow (Phase 2)
/ops hr                      → Employee list, skill matrix
/ops crm                     → Customer pipeline, deals (Phase 2)
/bridge-dashboard            → Unified CEO view (includes OPS data)
```
