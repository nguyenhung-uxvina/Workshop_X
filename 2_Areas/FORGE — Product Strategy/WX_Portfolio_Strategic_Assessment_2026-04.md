## 5. VN-CUAV-SIM: Vega Prime → Unity Migration Assessment

### 5.1 Engine Comparison

| Aspect | Vega Prime (current) | Unity (planned) |
|---|---|---|
| License | Presagis commercial, $$$ | Free (Runtime), $$$→free (build) |
| Ecosystem | Niche (mil-sim) | Massive (gaming + mil-sim) |
| VR support | Limited | Native |
| Physics engine | Basic | PhysX (advanced) |
| Visual quality | Good (mil-grade) | Excellent (gaming-grade) |
| Developer pool VN | Near zero | Large |
| WX IP ownership | No (licensed engine) | **Yes (own code)** |
| Long-term cost | Recurring license | One-time migration |
| Community | Tiny | Massive |
| C-UAV content | None | FPV drone assets available |

### 5.2 Migration Risk Assessment

| Risk | Impact | Mitigation |
|---|---|---|
| 6-12 months migration effort | HIGH | Phase approach: core rendering first, then physics, then scenarios |
| Existing sim customers expect Vega Prime support | MED | Maintain Vega Prime for existing 8 systems. New products = Unity. |
| Unity military acceptance | LOW | Unity widely used in mil-sim (Bohemia, CAE, Rheinmetall VBS4 competitors) |
| Visual fidelity gap during migration | MED | Acceptable for C-UAV (FPV drones are small, don't need photo-real terrain) |

### 5.3 Strategic Decision: Migration Strategy

| Option | Description | Risk | Time |
|---|---|---|---|
| **A: Clean break** | CUAV-SIM = 100% Unity. New codebase. | MED | 6-9 months |
| **B: Parallel** | Maintain Vega Prime (existing), Unity (new) | LOW but costly | Ongoing |
| **C: Gradual** | Port subsystems one at a time | LOW | 12-18 months |

**Recommendation: Option A — Clean break for CUAV-SIM.** Vega Prime stays for existing 8 systems (maintenance/support). All new products = Unity. CUAV-SIM is different enough (C-UAV vs naval gunnery) to justify new engine.

### 5.4 What Transfers from Vega Prime → CUAV-SIM

| Component | Reusable? | Notes |
|---|---|---|
| Ballistic algorithms | ✅ **YES** — math is engine-independent | V-SMASH core |
| Weapon kinematics | ✅ **YES** — physics models | Traverse/elevation math |
| Scenario logic | ✅ **PARTIAL** — game logic ports, rendering doesn't | 50% reuse |
| 3D models | ❌ **NO** — different format, different scale | Rebuild for Unity |
| Terrain/environment | ❌ **NO** — Vega Prime specific | Unity terrain tools |
| Scoring system | ✅ **YES** — algorithm independent | Ray-trace scoring is math |
| Networking/multi-station | ⚠️ **PARTIAL** — architecture transfers, implementation doesn't | 30% reuse |
| Training experience (know-how) | ✅ **YES** — most valuable asset | 8 systems of lessons learned |

**Reuse estimate: 40-50% of sim know-how transfers. 60% is new development.** CUAV-SIM TRL revised: **TRL 6** (proven sim capability, new engine platform).
