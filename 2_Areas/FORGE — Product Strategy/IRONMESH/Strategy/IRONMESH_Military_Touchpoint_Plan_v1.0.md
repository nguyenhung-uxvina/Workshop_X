# IRONMESH — Military Touchpoint Plan v1.0

> **The problem:** The trust-building cycle (B2) for Vietnamese military procurement
> is 1-3 years. The root cause isn't the technology — it's **infrequent, high-stakes interactions.**
> One annual formal presentation = 1 data point per year in the trust loop.
>
> **The fix:** Increase touchpoint FREQUENCY. Lower the stakes per interaction.
> Each low-stakes touchpoint compresses the trust timeline by adding data points faster.
>
> **Rule:** Never go >4 weeks without a touchpoint with the top 2 contacts.
> Consistency builds trust faster than any single impressive meeting.

---

## TOUCHPOINT STRATEGY — LOW TO HIGH STAKES

```
FREQUENCY TARGET: ≥1 touchpoint/month (vs current: sporadic, high-stakes only)

STAKE LADDER (use this sequence — don't skip levels):
  Level 1: Passive signal — share relevant news/update (no response required)
  Level 2: Brief question — ask for their input on something specific (low ask)
  Level 3: Update meeting — show progress, no pitch (15-20 min)
  Level 4: Demonstration — show working system, answer questions (30-45 min)
  Level 5: Proposal conversation — present solution to a named problem they have (60 min)
  Level 6: Formal proposal / procurement — full presentation (structured)

RULE: Never jump from Level 1 to Level 5. Each level builds the context for the next.
WHERE YOU ARE NOW: Level 1-2 for most contacts. Target: Level 3 by end of Month 1.
```

## WHY THIS MATTERS (the system perspective)

From the priority plan (B2: Trust Building Loop):

```
Current state (sporadic high-stakes):
  AI demo (Level 6) → Long gap → Military tests skeptically →
  KN not available → Trust resets → Another long gap

Target state (frequent low-stakes):
  Level 1 → reply → Level 2 → meeting → Level 3 → demo →
  Level 4 → proposal → Level 5 → contract
  Each level compresses the delay (L9 intervention)
```

**The anti-pattern:** Waiting until the product is perfect to make contact.
B-NS at 6/10 means each high-stakes interaction has a higher chance of falling flat.
**More low-stakes reps → higher B-NS → higher hit rate when it counts.**

Practice the briefing 3x/week. Make 2 touchpoints this month.
The technology is already good enough. The storytelling is the bottleneck.
