### 2.3 Revenue Gap Analysis

Vision doc projects $160M midpoint by 2036. Grounded estimate: $20-50M.

**Gap = $110-140M. Sources of gap:**
1. MSM family ($30-45M/yr vision) — requires naval architect + shipyard partnership. WX has 1 prototype (VN-XUONG-UUV), not production capability for 15-25m vessels.
2. UTT-Vehicle ($13-23M/yr vision) — requires $6-10M R&D investment + navigation/propulsion COTS. Not feasible with current team.
3. USV ($35-70M/yr vision) — deferred 2029+, requires LCS L3+ which doesn't exist.
4. STT scaling ($18-40M/yr vision) — requires 12-25 boat targets/year production. Possible but requires facility expansion.

**CEO Decision Point:** Vision gap is NOT a problem IF understood as aspiration. The $20-50M grounded trajectory is excellent growth from $3-6M base. Closing the gap requires either (a) external capital injection or (b) longer timeline.

## 6. ACH INTEGRATION — Missing from Vision Docs

Vision docs **không nhắc ACH** (AI-Compensates-Hardware). Đây là lỗ hổng. ACH là differentiator chiến lược của WX.

### 6.1 ACH Overlay on Product Families

| Family | ACH Opportunity | Status |
|---|---|---|
| TTS → UTT | Signature fidelity via AI compensation (commodity transducers + AI = premium signature) | Concept |
| TTS → ATT | Flight path optimization via AI (commodity airframe + AI autopilot = precision target) | Existing (simple autopilot) |
| TTS → STT | Autonomous behavior via AI (commodity boat + AI = realistic threat simulator) | Concept |
| MSM → LARS | AI-assisted L&R (simpler mechanical + AI motion comp = autonomous ops) | Concept (LCS L3+) |
| Sim → TMS | AI analytics (standard sim + AI = personalized training curriculum) | Planned (VN-AICC paused) |
| Cash Cows | MAINT-KIT + AI diagnostics = predictive maintenance for installed base | Concept |

### 6.2 ACH as Strategic Moat

Vision docs identify "signature coordination" as key technical moat. ACH adds:
- **Compound learning**: Every deployed unit generates training data
- **Cost advantage**: Commodity hardware + AI = premium performance at lower cost
- **Lock-in**: AI models improve with customer data → switching cost increases
- **Defense of position**: Competitors can copy hardware but not trained AI models
