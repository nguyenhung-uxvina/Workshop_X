## 4. State Machine

```
┌─────────────────────────────────────────────────────────────────────────┐
│                      V-SMASH OPERATIONAL STATE MACHINE                   │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│                              ┌─────────┐                                │
│                              │  BOOT   │                                │
│                              └────┬────┘                                │
│                                   │ Self-test pass                      │
│                                   ▼                                     │
│         ┌───────────────────┬─────────────┬───────────────────┐        │
│         │                   │             │                   │        │
│         ▼                   ▼             ▼                   │        │
│    ┌─────────┐        ┌─────────┐   ┌─────────┐              │        │
│    │  SAFE   │◄──────►│ STANDBY │──►│ ACTIVE  │──────────────┤        │
│    │         │        │         │   │         │              │        │
│    │ Manual  │        │ AI Ready│   │ Tracking│              │        │
│    │ Only    │        │ No Track│   │ Target  │              │        │
│    └─────────┘        └─────────┘   └────┬────┘              │        │
│         ▲                                │                    │        │
│         │                                │ Target locked +    │        │
│         │                                │ Fire solution OK   │        │
│         │                                ▼                    │        │
│         │                          ┌─────────┐               │        │
│         │                          │ ARMED   │               │        │
│         │                          │         │               │        │
│         │                          │ Gate    │               │        │
│         │                          │ Enabled │               │        │
│         │                          └────┬────┘               │        │
│         │                               │ Trigger + Aligned  │        │
│         │                               ▼                    │        │
│         │                          ┌─────────┐               │        │
│         │                          │  FIRE   │───────────────┘        │
│         │                          │         │ (returns to STANDBY)   │
│         │                          │ Release │                        │
│         │                          │ Trigger │                        │
│         │                          └─────────┘                        │
│         │                               │                             │
│         │                               │ Record engagement           │
│         │                               ▼                             │
│         │                          ┌─────────┐                        │
│         └──────────────────────────│  FAULT  │                        │
│               Any critical error   │         │                        │
│                                    │ Fail to │                        │
│                                    │ Manual  │                        │
│                                    └─────────┘                        │
│                                                                        │
└─────────────────────────────────────────────────────────────────────────┘

STATE TRANSITIONS:
• SAFE → STANDBY: Mode switch by operator
• STANDBY → ACTIVE: Target detected
• ACTIVE → ARMED: Fire solution valid
• ARMED → FIRE: Trigger + Alignment
• ANY → FAULT: Critical error
• FAULT → SAFE: Error cleared (or auto if weapon functional)
```
