## 🎯 Impact Sensor (AS)

> **Decision**: DEC-002 - Piezoelectric (PZT) selected over MEMS microphone
> **Rationale**: No SPL limit (vibration vs pressure), local sourcing, 58% cost reduction

| ID | Requirement | D/W | Value | Verification | Status |
|----|-------------|-----|-------|--------------|--------|
| AS.01 | Loại sensor | D | **Piezoelectric (PZT)** | I | ✅ DEC-002 |
| AS.02 | Số sensor/bia | D | 1-2 per target | I | ✅ |
| AS.03 | Tổng số sensor | D | 4-5 total | I | ✅ |
| AS.06 | Dải tần số | D | 100 Hz - 20 kHz | T | ✅ PZT covers |
| AS.07 | Impact detection | D | No saturation at 140dB+ | T | ✅ PZT = no SPL limit |
| **AS.08** | **SNR** | **D** | **≥20 dB** | **T** | ✅ |
| AS.09 | Hit detection accuracy | D | ≥95% | T | Pending test |
| AS.10 | False positive rate | W | <5% | T | Pending test |
| AS.11 | Detection latency | W | <100ms | T | ✅ Design target |

### DEC-002 Impact: Piezoelectric Advantages
| Old (Microphone) | New (Piezoelectric) |
|------------------|---------------------|
| SPL limit ~130-140dB | No SPL limit (vibration) |
| Acoustic membrane (IP65 hard) | Epoxy potting (IP68 easy) |
| Import sensor | Local sourcing (Nhật Tảo) |
| $98/unit | $41/unit (58% savings) |

### AS.08 SNR Requirement Details

```yaml
requirement_id: "AS.08"
name: "Acoustic Signal-to-Noise Ratio"
value: "≥20 dB"
type: "Demand"

definition:
  SNR: "20 * log10(Vsignal / Vnoise)"
  Vsignal: "RMS voltage của bullet impact event"
  Vnoise: "RMS voltage của background noise (wind, waves, boat)"

measurement_conditions:
  - Sea state: Beaufort 3 (moderate breeze, 0.5-1m waves)
  - Wind speed: ≤20 km/h
  - Distance from shore: >200m
  - No nearby vessel traffic

test_procedure:
  1: "Record 60s background noise (no shooting)"
  2: "Calculate RMS noise level"
  3: "Fire 10 rounds at each target"
  4: "Measure peak signal level for each impact"
  5: "Calculate SNR for each event"
  6: "Pass: ≥95% of impacts achieve SNR ≥20dB"

rationale:
  - "20dB SNR provides reliable detection threshold"
  - "Below 15dB: High false positive risk from wave impacts"
  - "Above 25dB: Over-specified, adds unnecessary cost"

design_implications:
  - "Microphone placement close to impact zone"
  - "High-pass filter to reject low-freq wave noise"
  - "Possible need for adaptive noise cancellation"
```
