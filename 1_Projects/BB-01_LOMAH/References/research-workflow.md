# Skill: Research Workflow

> **Use When**: Deep research on any technical or business topic
> **Output**: Structured research notes with actionable insights

---

## 🎯 Purpose

Transform research from random browsing into systematic knowledge capture that:
1. Captures key findings in retrievable format
2. Links to source evidence
3. Extracts actionable insights
4. Identifies knowledge gaps

---

## 🔄 Research Workflow (D-M-I-R)

### Phase 1: DIAGNOSIS (Define the Question)

**Before searching, clarify:**
```markdown
## Research: [Topic]

### Research Question
[Specific question to answer - not "learn about X" but "determine if X can do Y"]

### Success Criteria
- [ ] Can answer: [specific question 1]
- [ ] Can answer: [specific question 2]
- [ ] Have evidence for recommendation

### Scope Boundaries
- IN SCOPE: [what to include]
- OUT OF SCOPE: [what to exclude]
- TIME BOX: [max hours to spend]
```

### Phase 2: MODEL (Search Strategy)

**Plan before executing:**
```markdown
### Search Strategy
1. Primary sources: [where to look first]
2. Secondary sources: [backup sources]
3. Expert sources: [people/orgs to reference]

### Key Search Terms
- [term 1]
- [term 2]
- [term 1] + [term 2] combination
```

### Phase 3: INTERVENE (Execute Research)

**Capture findings systematically:**
```markdown
### Findings

#### Source 1: [Title]
- **URL**: [link]
- **Credibility**: [High/Medium/Low]
- **Key Points**:
  - [point 1]
  - [point 2]
- **Relevant Quote**: "[exact quote]"
- **My Interpretation**: [what this means for my question]

#### Source 2: [Title]
[same structure]
```

### Phase 4: REFLECT (Synthesize)

**Extract actionable conclusions:**
```markdown
### Synthesis

#### Answer to Research Question
[Direct answer based on evidence]

#### Confidence Level
[High/Medium/Low] because [reasons]

#### Key Insights
1. [insight 1]
2. [insight 2]
3. [insight 3]

#### Remaining Gaps
- [ ] Still need to find: [gap 1]
- [ ] Unclear about: [gap 2]

#### Recommended Actions
1. [action 1]
2. [action 2]

#### Links to Create
- [[related/topic/1]]
- [[related/topic/2]]
```

## ⚡ Quick Research (15 min)

For simple fact-finding:

```markdown
# Quick Research: [Topic]
**Date**: YYYY-MM-DD

**Question**: [What I need to know]

**Answer**: [What I found]

**Source**: [URL or reference]

**Confidence**: High/Medium/Low

**Action**: [What to do with this info]
```

---

## 📊 Source Credibility Assessment

| Level | Criteria | Examples |
|-------|----------|----------|
| **High** | Primary source, peer-reviewed, official docs | Datasheets, standards, academic papers |
| **Medium** | Reputable secondary source, expert opinion | Tech blogs, industry reports, tutorials |
| **Low** | Forum posts, unverified claims, old info | Reddit, random blogs, pre-2020 articles |

---

## 💡 Research Tips

1. **Time box aggressively** - Set 25 min timers, stop when done
2. **Answer the question** - Don't just collect info, synthesize it
3. **Capture quotes** - Exact quotes are searchable later
4. **Note credibility** - Not all sources are equal
5. **Link immediately** - Connect to existing notes while fresh
6. **Identify actions** - Research without action is wasted time
