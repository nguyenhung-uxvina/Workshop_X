# DECISION RECORD — DR-2026-03-08-01
**Date:** 2026-03-08 | **Project:** WX-KPIPE-001 + CEO-Self | **Phase:** Operations

## Decision
Áp dụng gate rule: "No new MCP server without matching SKILL.md" cho toàn bộ Workshop X.

## Context
Phân tích /learning --mode full trên "Sức Mạnh Kết Hợp: Giao Thức MCP và Kỹ Năng Agent" phát hiện Tool Overload Trap — biến thể Shifting the Burden. Workshop X có 30 skills nhưng chưa formal mapping giữa MCP servers và SKILL.md coverage.

## Alternatives Considered
| # | Option | Pros | Cons | Why Rejected |
|---|--------|------|------|-------------|
| A | Gate rule: no MCP without SKILL | Forces knowledge creation, reduces noise | Slower tool adoption | **SELECTED** |
| B | Add MCP freely, write skills later | Fast tool adoption | Skills never get written (Shifting Burden) | Defers fundamental solution |
| C | No formal rule, case-by-case | Flexible | No accountability, pattern repeats | Too loose |

## Information Used
- NLM analysis: "50 tools perfectly connected but still underperform without skills"
- Workshop X data: 30 SKILL.md files = compound asset, 6 MCP notebooks
- Systems analysis: R1 (Tool Accumulation Trap) vs R2 (Skill Compound) loop dynamics
- Galaxy: [[Shifting the Burden Archetype]], [[HOK Law — Tay Não Ký Ức Của Agent]]

## Information Gap
- Chưa biết chính xác mấy MCP server hiện tại KHÔNG có matching skill
- Chưa đo agent task success rate trước vs sau gate rule
- Chưa biết overhead thực tế của writing SKILL.md cho mỗi MCP server

## Decision Type
- **COD:** C (Core — CEO judgment về architecture)
- **Reversibility:** Easy (có thể bỏ rule bất kỳ lúc nào)
- **Time pressure:** Low (không deadline cấp bách)
- **Analogous to:** Galaxy quality gate (chỉ promote note đạt chuẩn) — same principle applied to tools
