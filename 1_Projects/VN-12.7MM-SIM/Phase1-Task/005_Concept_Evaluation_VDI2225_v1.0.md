# 5. SELECTION DECISION

## 5.1 Selected Concept: V2 STANDARD TRAINER

**Rationale:**
1. Highest normalized score (0.75) tied with V3
2. Meets cost constraint ($42,500 < $45,000)
3. Meets local content requirement (70%)
4. Good training effectiveness (80% transfer)
5. Manageable development risk
6. Reasonable maintainability

## 5.2 Enhancement Recommendations

To improve V2 toward V3 quality within budget:

| Enhancement | Cost | Benefit |
|-------------|------|---------|
| Upgrade to force sensor trigger | +$500 | Better feel |
| Add vibration feedback (basic) | +$1,000 | Recoil hint |
| Increase monitor size | +$1,000 | Better FOV |
| **Total enhancements** | **+$2,500** | **~5% fidelity gain** |

**Enhanced V2 Target Cost: $45,000** ✅
