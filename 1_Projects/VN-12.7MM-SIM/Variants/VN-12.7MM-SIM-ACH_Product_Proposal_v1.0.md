# VN-12.7MM-SIM-ACH — PRODUCT PROPOSAL

## 12.7mm AI-Coached Gunnery Trainer (IRONMESH Integration)

---

## 1. PRODUCT SUMMARY

- **Product name:** 12.7mm AI-Coached Gunnery Trainer
- **Codename:** HỒNG HẢI MASTER
- **Product code:** VN-12.7MM-SIM-ACH
- **Primary function:** Deliver personalized, adaptive gunnery training through real-time AI coaching — analyzing individual gunner performance patterns, providing voice-guided corrections, generating optimized drill sequences, and predicting combat readiness using longitudinal data.
- **Customer (who buys):** Vietnamese Navy Training Command — procured as software upgrade license to installed I-01 hardware base. No new hardware purchase required.
- **End-user (who uses):** 12.7mm gunner crews (same as I-01). Additionally: training unit commanders (readiness dashboard), Navy Training Command (fleet-wide analytics).
- **Target market:** All I-01 installations (6-8 training centers, 10-20 units). Revenue scales with installed base — every I-01 unit is a potential I-08 upgrade.

### Role in Product Family

```
I-08 is the IRONMESH INTEGRATION product:
  - Software-only upgrade: installs on existing I-01 hardware (no additional HW cost)
  - AI coaching layer: real-time voice guidance, personalized drills, weakness detection
  - Readiness prediction: individual gunner combat-readiness score based on longitudinal data
  - Fleet analytics: aggregate data across all installations → Navy-wide training optimization
  - R2 revenue loop: recurring license revenue per installed unit per year
```

## 4. WORKING PRINCIPLE OPTIONS (3 — Phase 2 Selects)

### Option A: Rule-Based Coaching

- Expert system: hand-coded rules from gunnery instructor knowledge
- "If burst > 4 rounds AND miss > 50m, THEN correct: shorten bursts, lead more"
- Voice cues from pre-recorded instructor audio library
- **Pros:** No ML training data needed. Works from day 1. Explainable to military.
- **Cons:** Cannot personalize. Cannot discover novel error patterns. Scales poorly.
- **Development:** ~$15K, 6 months
- **ACH leverage:** LOW — rules don't improve with data

### Option B: ML-Based Adaptive Coaching

- Performance data → ML model identifies individual gunner weakness patterns
- Personalized drill sequences generated per gunner
- Real-time coaching via Vietnamese TTS: corrections, encouragement, progression cues
- Readiness prediction: trained on sim-to-live correlation data (requires I-01 + live-fire pairs)
- **Pros:** Improves with data. Personalized. Discovers non-obvious patterns.
- **Cons:** Requires training data (≥500 sessions). Black-box decisions need explanation layer.
- **Development:** ~$40K, 12 months
- **ACH leverage:** HIGH — this IS the IRONMESH value proposition

### Option C: Hybrid — Rules Bootstrap + ML Takeover

- Phase 1 (months 1-6): Rule-based coaching active. Captures performance data.
- Phase 2 (months 6-12): ML model trains on accumulated data. Rules stay as fallback.
- Phase 3 (month 12+): ML coaching primary. Rules fire only when ML confidence < threshold.
- Readiness prediction added when ≥500 session threshold met.
- **Pros:** Ships value immediately (rules). Gets smarter over time (ML). Graceful degradation.
- **Cons:** Highest development effort. Two systems to maintain initially.
- **Development:** ~$45K, 12 months (but delivers value at month 6)
- **ACH leverage:** MAXIMUM — demonstrates AI improving over time. Compelling for procurement narrative.

**Recommendation:** Option C (Hybrid). The rule-based bootstrap solves the cold-start problem — I-08 delivers coaching value from day 1, even before ML models are trained. The progressive takeover from rules to ML is a powerful procurement narrative: "the system literally gets smarter the more your gunners train."

## 5. RISK ASSESSMENT

### Technical: MEDIUM

- **Top concern:** IRONMESH platform maturity. I-08 assumes IRONMESH provides: data pipeline, ML model serving, coaching API, analytics dashboard. If IRONMESH is not production-ready when I-08 development starts, I-08 becomes a platform build project (not an integration project) — 3× cost and time overrun.
- **Mitigation:** DG-3 dependency gate explicitly verifies IRONMESH readiness before I-08 Phase 2 starts. I-08 Phase 0/1 can proceed in parallel (requirements don't depend on platform).
- **Secondary:** Voice coaching in Vietnamese — natural-sounding TTS for military context may require fine-tuned Vietnamese language model. Current Vietnamese TTS quality is adequate for simple commands but may sound robotic for nuanced coaching.
- **Tertiary:** ML model accuracy — depends on data quality from I-01. If I-01 scoring has systematic biases (CHK-08: false positive rate not specified), coaching models inherit those biases.

### Schedule: MEDIUM

- **Top concern:** Double dependency (DG-2 + DG-3) means I-08 cannot fully start until both I-01 hardware AND IRONMESH platform are ready. Estimated: 6-9 months from now. If either slips, I-08 start date slips.
- **Mitigation:** Phase 0/1 work (requirements, coaching logic design, rule-based system specification) can proceed before dependencies are met. Only Phase 2+ (ML integration, platform coupling) is blocked.
- **Secondary:** Validation trial (coached vs uncoached) requires 40+ gunners and 3+ months. Must be planned early to align with Navy training calendar.

### Market: LOW-MEDIUM

- **Top concern:** Military AI acceptance — Vietnamese Navy may be cautious about AI-driven training decisions. "Can we trust the AI's readiness assessment?" is a valid concern. Mitigation: all AI recommendations are advisory — instructor retains final authority. Explainability layer shows WHY the AI recommended specific drills.
- **Secondary:** Recurring license model may face procurement resistance — Vietnamese military procurement is structured for one-time purchases, not annual subscriptions. Mitigation: offer 3-year or 5-year license bundles prepaid. Or: include 3-year license in initial I-01 purchase price.

### Kill Condition

> **If coaching effectiveness trial shows no statistically significant improvement (p > 0.05) in time-to-qualification after 6-month controlled study with ≥20 gunners per group, STOP I-08 as a standalone product.** Pivot option: integrate coaching as a free value-add feature in I-01 v2.0 software update (reduces I-08 revenue to zero but preserves IRONMESH data pipeline value and customer relationship).
