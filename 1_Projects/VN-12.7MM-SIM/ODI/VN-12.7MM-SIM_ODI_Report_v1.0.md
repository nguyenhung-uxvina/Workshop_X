### Phase 1 Feed — QC Gate Addenda

**FLAG-03 (TCVN/Regulatory):** New requirements from ODI must reference applicable standards:
- O19 (shore-based accessibility): TCVN 7699-2-1 (thermal), IEC 60950 (electrical safety for training facility), fire safety per local building code
- O18 (data retention 12 months): TCVN data handling standards if PII involved (gunner names + scores); MoD data classification if training records are restricted

**FLAG-05 (Environmental):** Deployment scope constraint for Phase 1:
- Simulator designed for **shore-based training center only** (indoor, climate-controlled, 18-32°C, grid power)
- Shipboard deployment = separate requirements analysis (adds MIL-STD-810 Method 514 vibration, salt spray, shock — fundamentally different environmental envelope)
- All environmental requirements in 002_Requirements_List scoped to indoor/shore-based unless explicitly marked otherwise

**FLAG-08 (Dual-Error Rate):** Scoring system error specification required in Phase 1:
- O12 (shot placement accuracy) and O20 (sim-to-live correlation) require dual-error specification
- For qualification scoring systems: **false-positive (score inflation) is the critical error direction** — a gunner who passes sim but fails live-fire is more dangerous than one who fails sim but passes live-fire
- Phase 1 must specify: max acceptable false-hit rate, max acceptable false-miss rate, and target sim-to-live correlation coefficient (recommend r² ≥ 0.75 as MUST, ≥ 0.85 as WISH)

**FLAG-11 (Accountability):** Validation dependency:
- I/S scores in this report are AI-estimated (30% L5 assumptions). Phase 1 requirement WEIGHTS derived from these scores
- **Before finalizing VDI 2225 criteria weights:** validate I/S scores with 3-5 Navy gunnery instructors (field interviews)
- If validation changes any top-5 outcome by ≥2 points on I or S scale → re-run opportunity scores and update Phase 1 feed
