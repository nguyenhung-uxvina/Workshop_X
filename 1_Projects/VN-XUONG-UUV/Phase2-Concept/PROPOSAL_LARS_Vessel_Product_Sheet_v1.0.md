## 1. SOLUTION OVERVIEW

Workshop X offers a **purpose-built 8m aluminum Launch and Recovery System (LARS) vessel** designed for deployment and recovery of tethered UUVs in the 300–700 kg class.

Unlike adapted commercial boats or RIB-based solutions, the WX LARS Vessel is engineered from the ground up for a single mission: **safe, reliable UUV launch and recovery at Sea State 3**, with full operations achievable by a 3-person crew.

### Key Differentiators

| Feature | WX LARS Vessel | Conventional Approach |
|---------|----------------|----------------------|
| Hull | Purpose-built aluminum 5083 | Adapted commercial boat |
| LARS | Integrated electric stern ramp + V-funnel | Bolt-on crane or A-frame |
| Recovery | Passive V-funnel capture — no diver needed | Manual hook-up or net capture |
| Crew | 3 persons (minimum) | 4–6+ persons typical |
| UUV contact surfaces | Full UHMWPE lining | Metal-on-metal or rubber pads |
| Power | Electric LARS (VFD) — clean, precise | Hydraulic — leak risk, maintenance |
| Pendant | Permanent (always attached to cradle) | Detachable hook — crew exposure |

### Design Heritage

The stern ramp + V-funnel recovery concept is based on **30+ years of proven US Navy Torpedo Recovery Vessel (TRV) operations**, adapted for the 500 kg UUV class with modern electric actuation and optimized for tropical sea conditions.

## 3. OPERATIONAL CONCEPT

### 3.1 Mission Profile

```
┌─────────────────────────────────────────────────────────┐
│  PHASE A — TRANSIT                          30–60 min   │
│  Tow alongside mother ship or self-transit at 25 kts    │
├─────────────────────────────────────────────────────────┤
│  PHASE B — PREPARE & LAUNCH                 ~35 min     │
│  Receive UUV via mother ship crane (≥1.0t SWL)          │
│  Secure in cradle → Connect tether → Deploy down ramp   │
├─────────────────────────────────────────────────────────┤
│  PHASE C — UUV MISSION                      Variable    │
│  Vessel station-keeps while UUV operates                │
│  Tether managed by UUV internal systems                 │
├─────────────────────────────────────────────────────────┤
│  PHASE D — RECOVERY                         ~30 min     │
│  Approach UUV stern-first → V-funnel passive capture    │
│  Winch up ramp (permanent pendant) → Secure in cradle   │
├─────────────────────────────────────────────────────────┤
│  PHASE E — RETURN                           30–60 min   │
│  Transfer UUV to mother ship → Tow back or self-transit │
└─────────────────────────────────────────────────────────┘
```

### 3.2 Crew Roles

| Role | Station | Responsibilities |
|------|---------|------------------|
| Helmsman / Commander | Forward console | Navigation, station-keeping, abort authority |
| LARS Operator | Midship | Winch, ramp actuator, cradle clamps, deck operations |
| UUV Operator | Console station | UUV commands via OEM controller, tether monitoring |

### 3.3 Mother Ship Interface

- UUV loading: via mother ship crane (minimum SWL 1.0 t)
- Vessel deployment: towed alongside (primary) or self-transit (secondary)
- Communications: VHF radio
